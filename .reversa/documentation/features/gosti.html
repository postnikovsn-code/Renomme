Гости и регистрация

Как устроена фича · модуль «Гости и регистрация» 23 320 строк сложность: высокая

Модуль ведёт центральную сущность гостя/контрагента (Catalog.Клиенты, около 130 реквизитов и 5 ТЧ) и весь жизненный цикл вокруг неё: классификацию, контакты и адреса, анкетирование, распознавание паспортов через PassportBox, выгрузку проживающих в ФМС, дедупликацию и объединение клиентов, загрузку сканов и отбор именинников.

Назначение

Хранит карточку клиента (физ/юрлицо) с многоступенчатым антидублем при записи и классификацией по типу, виду и категории.

Обеспечивает регуляторные сценарии: распознавание паспорта через HTTP-сканер и формирование CSV-файла миграционного учёта для ФМС.

Поддерживает чистоту данных: дедупликацию юрлиц по ИНН и каскадное объединение клиентов с заменой ссылок во всех документах и регистрах.

Бизнес-правила

  • GR-01Антидубль перед записью в 3 ступени: по наименованию (физлица — авто-сборка из ФИО), по ИНН плюс КПП, через ПроверитьКонтрагента. При дубле запись отменяется, открывается существующий.
  • GR-03ГУИД_ИсточникОбмена присваивается из UID ссылки при первой записи (ключ интеграции/обмена).
  • GR-04Распознавание паспорта: 3 источника по приоритету page3 ниже OCR ниже MRZ; непустое более приоритетное перезаписывает менее приоритетное; ФИО приводится к нужному регистру.
  • GR-05Выгрузка ФМС ветвится по ИностранныйГражданин: для россиян гражданство RUS, тип документа 103008, поля визы/мигркарты пустые.
  • GR-06Дедупликация по ИНН охватывает только юрлиц; дубли физлиц автоматически не выявляются.
  • GR-07При объединении исходный помечается на удаление только при отсутствии ссылок; замена каскадная во всех заявках/счетах/выписках/регистрах.
  • GR-08Именинник среди проживающих — если день/месяц рождения попадает в интервал активной брони (Статус=Проживает); учитываются Клиент и Клиент2.

Крайние случаи

  • Сканер вернул не тот тип документа (doc_type не паспорт РФ) — возвращается ошибка «Неверный тип документа», реквизиты не записываются.
  • Объединение клиентов выполняется в транзакции, но Записать(Проведение) внутри цикла не обёрнут в Попытка — при сбое возможна несогласованность ссылок 🔴.
  • Каталог выгрузки ФМС недоступен/не задан — файл не создаётся, выводится сообщение об ошибке записи.
  • Загрузка скана: при коллизии имени приёмного файла суффикс авто-инкрементируется; оригинал копируется в архив и приёмник, затем удаляется.

Открытые вопросы

  • 🔴 Q-01Магическое число типа документа 103008 (паспорт РФ) зашито в двух местах — откуда и стабильно ли.
  • 🔴 Q-02Незавершённая миграция реквизитов _NEW/_OLD ФМС — какая модель актуальна, что удалять.
  • 🔴 Q-03Объединение клиентов: запись в цикле без Попытка и без отмены транзакции при сбое.
  • 🔴 Q-04Внешние классификаторы ФМС (*ФМС_NEW) — источник, обновление, семантика полей.
  • 🔴 Q-05Document.АнкетаНовая: 5 ТЧ ответов не разобраны, логика построения формы по типу ответа.
  • 🟡 Q-09Политика хранения ПДн и сканов паспортов (152-ФЗ): шифрование, срок, удаление.
