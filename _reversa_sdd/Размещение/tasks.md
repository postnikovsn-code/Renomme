# Размещение и номерной фонд — Задачи реализации

> Файл `tasks.md`. Атомарные задачи для переподнятия модуля из легаси, с прослеживаемостью к коду.
> Каждая задача: цитата легаси-файла + критерий готовности + метка доверия 🟢/🟡/🔴.

## Pré-requisitos / Предусловия

- [ ] Доступны зависимости из `design.md`: модуль **Бронирование** (запись `ЗанятостьНомеров`/`ПроданныеНомера`), модуль **Горничные** (внешняя БД, `ГорничныеНомера`).
- [ ] Платформа 1С:Предприятие 8.3, формат 1C:EDT, скрипт-вариант Russian.
- [ ] Предопределённый элемент `Справочники.Замечания.Нет` существует (нужен `ОсмотрНомера`).
- [ ] Константы `ОбменСГорничными` (Булево), `Папка_Горничные` объявлены.
- [ ] Для COM-импорта: вынесенные из кода кредитные данные/пути (см. 🔴 в questions.md) — НЕ хардкодить.
