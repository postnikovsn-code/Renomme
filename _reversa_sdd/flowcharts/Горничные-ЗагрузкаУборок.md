# Flowchart — Загрузка фактов уборки из БД горничных

`CommonModule.ОбменГорничныеСервер.ЗагрузитьОбслуживаниеНомеров`. Доверие: 🟢.

```mermaid
flowchart TD
    Старт[ЗагрузитьОбслуживаниеНомеров С, По, НомерГорничные] --> Тумблер{ОбменСГорничными?}
    Тумблер -- Ложь --> Выход[выход]
    Тумблер -- Истина --> Соед[Соединение: COM к файловой БД горничных]
    Соед --> ЕстьСоед{Соединение?}
    ЕстьСоед -- нет --> Сообщить1[Сообщить «нет связи»] --> Выход
    ЕстьСоед -- да --> Выгрузка[COM: ВыгрузитьОбслуживаниеНомеров -> ТЗ]
    Выгрузка --> КэшЗапросы[Кэш-запросы: существующие документы,\nНомернойФонд, ГорничныеНомера]
    КэшЗапросы --> Цикл[Для каждой строки ТЗ]

    Цикл --> Найти[Сопоставить номер по НомерГорничные,\nгорничную по наименованию, заявку по GUID]
    Найти --> ЕстьГорн{Горничная найдена?}
    ЕстьГорн -- нет --> Создать[Авто-создать Catalog.Горничные]
    ЕстьГорн -- да --> Док
    Создать --> Док{Документ по ключу\nДата+пп+НомерГорничные?}
    Док -- нет --> Новый[Документы.СоздатьДокумент,\nпроверки заполненности номеров]
    Док -- да --> Сущ[Получить объект]
    Сущ --> Ручное{РучноеИзменение?}
    Ручное -- да --> Пропуск[Продолжить — не перезаписывать]
    Ручное -- нет --> Заполн
    Новый --> Заполн[Заполнить реквизиты + ТЧ\nМинибар/ТехНеисправности/ДопОборудование]
    Заполн --> ПометкаУд{ПометкаУдаления из БД?}
    ПометкаУд -- да --> Запись1[Записать без проведения + пометить]
    ПометкаУд -- нет --> Запись2[Записать с проведением] --> РСУборки[(РС УборкиНомеров)]
    Запись1 --> Цикл
    Запись2 --> Цикл
    Пропуск --> Цикл

    Цикл --> Состояние[ЗагрузитьСостояниеНомеров:\nбельё/доп.места/оборудование в ГорничныеНомера]
```

## Примечания
- 🟢 Защита ручных правок: документ с `РучноеИзменение=Истина` не перезаписывается.
- 🟢 Минибар сопоставляется по коду (`НоменклатураМиниБара.НайтиПоКоду`); цена берётся из карточки.
- 🟡 Аналогичные потоки: `ЗагрузитьОбслуживаниеПомещений` (ключ Дата+пп+Горничная), `ЗагрузитьСмены` (ключ ДатаСмены+Горничная).
