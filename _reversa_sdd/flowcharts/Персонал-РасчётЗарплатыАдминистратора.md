# Flowchart функции: Расчёт зарплаты администратора (детально)

> Источник: `ПСН_РЕНОМЕ__АУДИТ/src/Documents/АдминистраторыЗарплата/Forms/ФормаДокумента/Module.bsl`
> Доверие: 🟢 ПОДТВЕРЖДЕНО (формулы извлечены построчно).

## Формулы расчёта по администратору

```mermaid
flowchart TD
    Start([Строка ЗарплатаСмены: один администратор]) --> Stazh[НадбавкаЗаСтаж]
    Start --> Stand[НадбавкаЗаСтандарты]
    Start --> Lang[НадбавкаЗаИнЯзыки]
    Start --> Perm{Постоянный?}

    Stazh --> StazhCalc["СуммаНадбавкаЗаСтаж (стр.2560):<br/>если ДатаПриема пуста ИЛИ НеНачислятьЗаСтаж → 0<br/>РазницаВДнях = ДК − ДатаПриема<br/>поиск в РС НадбавкаЗаСтаж: С ≤ РазницаВДнях < По → Сумма<br/>× РасчДней / ДнейМесяца, Окр"]

    Stand --> StandCalc["СуммаНадбавкаЗаСтандарты (стр.2533):<br/>Справочник.НадбавкаЗаСтандарты<br/>× (ДК−ДН+1) / ДнейМесяца, Окр"]

    Lang --> LangCalc["СуммаНадбавкаЗаИнЯзыки (стр.2547):<br/>Справочник.НадбавкаЗаИнЯзыки<br/>× (ДК−ДН+1) / ДнейМесяца, Окр"]

    Perm -->|Да| PermCalc["РасчитатьПостоянный (стр.2491):<br/>РасчДней = (ДК−ДН+1) − ДнейОтпуска (НомерСмены=3)<br/>Оклад = СуммаОклад × РасчДней / ДнейМесяца<br/>СуммаЗаПроживающих = НадбавкаЗаПроживающих × РасчДней / ДнейМесяца"]
    Perm -->|Нет| Shifts["Сдельный (по сменам):<br/>сумма ОкладЗаСмену + переработка + заселения + завтраки + проживающие по дням"]

    StazhCalc --> Eff
    StandCalc --> Eff
    LangCalc --> Eff
    PermCalc --> Eff
    Shifts --> Eff[ОбновитьСтрокаЗарплатаСменыОсновные_Э:<br/>применить И/Р по _Есть]
    Eff --> Itogo
```

## Оклад за смену (сдельный администратор) — `ОкладЗаСмену` (стр.2866)

```mermaid
flowchart TD
    Start([ОкладЗаСмену Администратор, ДлинаСмены]) --> Z{ДлинаСмены = 0?}
    Z -->|Да| R0[Возврат 0]
    Z -->|Нет| L12{ДлинаСмены ≤ 12?}
    L12 -->|Да| C12["Окр СтавкаЗаСмену12 × ДлинаСмены/12"]
    L12 -->|Нет| L24{12 < ДлинаСмены ≤ 24?}
    L24 -->|Да| C24["Окр СтавкаЗаСмену24 × ДлинаСмены/24"]
    L24 -->|Нет| Cmax["СтавкаЗаСмену24 (полная, без пропорции)"]
```

## Номер смены — валидация и семантика (стр.2600 `НомерСмены_ПриИзменении`)

```mermaid
flowchart TD
    Start([Изменение НомерСмены_DDMMYY]) --> Perm{Администратор.Постоянный?}
    Perm -->|Да| ChkP{НомерСмены ∈ 3,4?}
    Perm -->|Нет| ChkS{НомерСмены ∈ 1,2,3?}
    ChkP -->|нет| RejP[Предупреждение: «д.б. 0 или 3 или 4»<br/>откат к прежнему значению]
    ChkS -->|нет| RejS[Предупреждение: «д.б. 0 или 1 или 2 или 3»<br/>откат к прежнему значению]
    ChkP -->|да| S4
    ChkS -->|да| S4
    S4{НомерСмены = 4?}
    S4 -->|Да| Def8[Если ДлинаСмены=0 → ДлинаСмены=8]
    S4 -->|Нет| Recalc
    Def8 --> Recalc[РасчитатьСтрокаЗарплатаСмены_НаСервере]
```

> Семантика номеров смен (🟡 ВЫВЕДЕНО из валидаций и `КоличествоРасчетныхДней`):
> - **0** — администратор не работал в этот день;
> - **1** — дневная смена (старт 09:00, `ManagerModule.ДатаВремяСмена`);
> - **2** — ночная смена (старт 21:00);
> - **3** — отпуск/отпускной день (исключается из расчётных дней постоянного, `КоличествоРасчетныхДней` стр.2521);
> - **4** — особая смена для постоянных (по умолчанию ДлинаСмены=8).

## Сумма за проживающих за смену — `СуммаЗаПроживающихЗаСмену` (Manager, стр.54)

```mermaid
flowchart TD
    Start([По КоличествоНомеров на дату и ДлинаСмены]) --> Empty{Шкала РС СуммаЗаПроживающих пуста?}
    Empty -->|Да| R0[Возврат 0]
    Empty -->|Нет| Loop{Для каждой строки шкалы}
    Loop --> Band{КоличествоНомеровС ≤ КолНомеров < КоличествоНомеровПо?}
    Band -->|Да| Len{ДлинаСмены ≤ 12?}
    Band -->|Нет| Loop
    Len -->|Да| S12[Возврат Сумма_12]
    Len -->|Нет| S24[Возврат Сумма_24]
    Loop -->|не найдено| R0b[Возврат 0]
```
