# Доп. услуги и коворкинг — Задачи реализации

> Файл `tasks.md`. Атомарные задачи для переподнятия модуля из легаси с прослеживаемостью к исходному коду. Каждая задача цитирует легаси-файл, несёт критерий готовности и доверие 🟢/🟡/🔴.

## Предпосылки

- [ ] Доступны зависимости из `design.md` (модули «Минибар», «Финансы и касса», «Бронирование», «Гости»).
- [ ] Перечисление `Enum.ПрограммныйКодУслуги` создано со значениями `ТРАНСПОРТНЫЕ_УСЛУГИ`, `ПРОЖИВАНИЕ_УСЛУГИ`, `ЗАВТРАКИ`, `КОВОРКИНГ`, `МИНИБАР`, `ПРАЧЕЧНАЯ`, `ШТРАФ`.
- [ ] `Справочник.ВидыОпераций` содержит предопределённый `СписаниеДопУслуг`.
- [ ] Доступны `ОплатыОбщееСервер` и `ЗаявкаСервер` (контракты финансов/брони).
