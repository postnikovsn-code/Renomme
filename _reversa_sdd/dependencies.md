# Зависимости и интеграции — ОТЕЛЬ

> Сгенерировано Scout (Reversa) · 2026-06-06
> Шкала доверия: 🟢 ПОДТВЕРЖДЕНО · 🟡 ВЫВЕДЕНО · 🔴 ПРОБЕЛ

## 1. Платформенные зависимости

🟢 В 1С нет менеджера пакетов в привычном смысле (npm/pip). «Зависимости» — это платформа, типовые библиотеки и родительские конфигурации.

| Зависимость | Версия / источник | Доверие |
|-------------|-------------------|---------|
| Платформа 1С:Предприятие | режим совместимости `8.3.24`; расширения `8.3.27` | 🟢 |
| Конфигурация «ОТЕЛЬ» | `3.2.7.38` | 🟢 |
| Библиотека подключаемого оборудования (БПО) | редакция `3.2` (`briefInformation`) | 🟢 |
| Поставщик | Фирма «1С» / ООО «1C-Софт» | 🟢 |
| Родительские конфигурации | `Configuration/ParentConfigurations/` | 🟡 (требует чтения для точного состава) |

> Корневой `package.json` репозитория (`{ "dependencies": { "reversa": "file:reversa" } }`) относится **к инструменту Reversa**, а не к анализируемой системе. К домену «ОТЕЛЬ» отношения не имеет.

## 2. Внешнее оборудование (БПО)

🟢 Система интегрирована с торговым/фискальным оборудованием через библиотеку подключаемого оборудования. Подсистемы:

- `ЧекопечатающиеУстройства` (ККТ), `АвтономнаяККТ`, `ОблачныеККТ`, `РаспределеннаяФискализация`
- `ПлатежныеСистемы` (эквайринг)
- `Маркировка` + `ФорматноЛогическийКонтроль` (проверка КМ)
- `УстройствоРаспознавания`
- `ЭлектронныеСертификаты` / `СертификатыНУЦМинцифры`
- `НесертифицированноеОборудование`

🟢 67 файлов `*.addin` — описания внешних компонент (драйверы устройств).
🟢 Конкретные драйверы: справочник `ДрайверыОборудования`, обработка `АТОЛ10106` (драйвер ККТ АТОЛ).

## 3. Внешние сервисы и интеграции

🟢 Обнаружены по именам общих модулей/обработок и сигналам HTTP-вызовов (`HTTPСоединение`, `HTTPЗапрос`, `WSПрокси`):

| Интеграция | Артефакты | Назначение (🟡) | Доверие |
|------------|-----------|-----------------|---------|
| **WhatsApp (Green API)** | `GREEN_WhatsApp`, `WhatsAppСервер`, `РассылкаWhatsApp`, `GreenAPI`, обработка `GREEN_MAX` | Уведомления/рассылки гостям через WhatsApp | 🟢 |
| **Telegram** | `TelegramСервер`, обработка `GREEN_Telegram` | Уведомления/бот через Telegram | 🟢 |
| **PayKeeper** | `PayKeeper`, обработка `PayKeeper_ТЕСТ` | Платёжный эквайринг / онлайн-оплата | 🟢 |
| **PassportBox** | `PassportBoxВызовСервера`, `НастройкиPassportBox`, `ЗагрузкаСканов` | Распознавание паспортов гостей | 🟢 |
| **Обмен с сайтом** | `ОбменСайт`, `ОбменHTTP`, `ОбменКартинкаСервер`, документ `ЗаявкаСайт` | Приём бронирований с сайта/каналов | 🟢 |
| **ФМС / МВД** | обработки `ВыгрузкаДляФМС`, `ВыгрузкаДляФМС_Исходная` | Регистрация гостей (миграционный учёт) | 🟢 |
| **Бухгалтерия / НДС** | `ОбменБухгалтерияНДС`, `ВыгрузкаНДС` | Выгрузка в учётную систему | 🟢 |
| **Банк (выписка)** | `ОбменВыписка`, документ `ВыпискаБанка`, план обмена `ВГ_ВыпискаГостиницы` | Загрузка банковских выписок | 🟢 |
| **СерверККМ** | `СерверККМ` | Серверная фискализация ККМ | 🟡 |
| **HTTP-инфраструктура** | `HTTP_Модуль`, `ОбменHTTP`, `HttpBridgeКлиент`, подсистема `HttpBridge` | Низкоуровневый HTTP-транспорт | 🟢 |

## 4. Планы обмена (синхронизация данных)

🟢 Три плана обмена:
- `ОбменГостиницы` — основной обмен данными гостиницы.
- `ВГ_ВыпискаГостиницы` — обмен банковскими выписками.
- `ОбменТест` — тестовый план обмена.

🟢 Серверные модули обмена: `ОбменГостиницы`, `ОбменГорничныеСервер`, `ОбменЗаселенияСервер`, `ОбменКартинкаСервер`, `ОбменВыписка`, `ОбменБухгалтерияНДС`.
🟢 XDTO-пакеты (2) — схемы сериализации для обмена.

## 5. Регламентные задания (фоновые процессы)

🟢 Шесть заданий, все из инфраструктуры БПО:
- `ОчисткаИсторииОперацийОчередиЧеков`
- `ОчисткаИсторииОперацийПроверкиКМ`
- `ОчисткаИсторииОперацийСОборудованием`
- `ОчисткаИсторииПлатежныхОпераций`
- `ОчисткаИсторииФискальныхОпераций`
- `РассылкаЭлектронныхЧеков`

🔴 **ПРОБЕЛ:** регламентные задания именно гостиничного домена (например автозагрузка бронирований с сайта, ежедневный аудит по расписанию) в списке `ScheduledJobs` не видны — возможно, запускаются иначе. Требует уточнения на этапе раскопок.

## 6. Безопасность и доступ (RBAC)

🟢 7 ролей: `ПолныеПрава`, `АдминистраторСистемы`, `Администратор`, `БазовыеПраваБПО`, `ВыполнениеСинхронизацииДанных`, `ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок`, `СохранениеДанныхПользователя`.
🟢 Роли по умолчанию: `ПолныеПрава`, `АдминистраторСистемы`, `ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок`.
> Детальная матрица прав — задача **Детектива**.

## 7. Открытые вопросы (🔴 ПРОБЕЛ)

- Точный состав родительских конфигураций (`ParentConfigurations/`).
- Конфигурация подключений внешних сервисов (токены Green API, PayKeeper, PassportBox) — хранится в Constants/InformationRegisters? Требует разбора.
- Наличие/отсутствие автоматизированных тестов.
- Способ запуска доменных фоновых процессов (если не через `ScheduledJobs`).
