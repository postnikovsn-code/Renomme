# Интеграции и обмен — Задачи реализации

> Файл `tasks.md`. Атомарные задачи для переподнятия модуля из легаси, с цитатой источника, критерием готовности и доверием 🟢/🟡/🔴.
> Корень легаси: `ПСН_РЕНОМЕ__АУДИТ/src`.

## Предварительные условия

- [ ] Зависимости из `design.md` доступны (`ФТПСервер`, инфраструктура планов обмена, Green API, PayKeeper, `Обработка.GREEN_Telegram`).
- [ ] Регистры сведений `PayKeeperПлатежи` и `РассылкаWhatsApp` существуют (см. `data-dictionary.md`).
- [ ] Константы каналов/токенов/серверов заведены: `GREENIdInstance_*`, `GREENApiToken_*`, `Сервер*HTTP`, флаги `СообщенияЧерез*`.
- [ ] 🔴 Секреты вынесены из исходников в защищённое хранилище (см. `questions.md`) ПЕРЕД продакшен-сборкой.

- [ ] T-02 — Реализовать единую структуру-ответ транспорта `{Ошибка:Булево, КодОшибки:Число, Описание:Строка, Данные/ДанныеJSON}`.

2. T-06 → T-03..T-05 (планы обмена) и T-15..T-16 (token-сессия PayKeeper).

## Пробелы, требующие валидации (🔴)

- T-21: XDTO-схемы `.xdto` не разобраны — нельзя реализовать сериализацию без них.
- Все секреты (FTP/Telegram/COM) должны быть вынесены до реализации продакшен-транспорта — см. `questions.md`.
- Системное журналирование ошибок интеграций не подтверждено — уточнить требования к наблюдаемости.
