> Все три документа имеют идентичную структуру `ОбработкаПроведения`.

```mermaid
flowchart TD
    A["ОбработкаПроведения(Отказ, Режим)"] --> B["Ответ = ТекстОшибки()"]
    B --> C{"ЗначениеЗаполнено(Ответ)?"}
    C -->|"Да (есть ошибки)"| D["Сообщить(ТекстСообщение + ' Документ НЕ сохранен')<br/>Отказ = Истина"]
    D --> E["Возврат — документ не проводится"]
    C -->|"Нет"| F["Движение = Движения.Взаиморасчеты.Добавить()"]
    F --> G["ВидДвижения = ?(Приход, Приход, Расход)<br/>Период = ДатаОплаты<br/>Контрагент = ОтКого<br/>Сумма = Сумма"]
    G --> H["Возврат  ◄── ранний выход!"]
    H --> X["🔴 Весь код ниже (Движения.Деньги,<br/>Движения.Долги, начисление бонусов) —<br/>МЁРТВЫЙ: никогда не выполняется"]

    style H fill:#fdd
    style X fill:#fdd
```

## Валидация — Функция ТекстОшибки() 🟢

```mermaid
flowchart TD
    V["ТекстОшибки()"] --> V1{"ДатаОплаты пусто?"}
    V1 -->|"Да"| VE1["+ 'Дата оплаты - пусто'"]
    V --> V2{"ОтКого пусто?"}
    V2 -->|"Да"| VE2["+ 'От кого - пусто'"]
    V --> V3{"Сумма = 0?<br/>(КассовыйДокумент: и ВыпискаБанка)"}
    V3 -->|"Да"| VE3["+ 'Сумма = 0'"]
    V --> V4{"КассовыйДокумент:<br/>Сумма ≠ СуммаКарта + СуммаНаличные?"}
    V4 -->|"Да"| VE4["+ 'Сумма <> Карта + Наличные'"]
    VE1 & VE2 & VE3 & VE4 --> R{"Есть предупреждения?"}
    R -->|"Да"| RR["Структура{ТекстПредупреждение, ТекстСообщение}"]
    R -->|"Нет"| RN["Неопределено (валидно)"]
```

## Ключевые правила
- Знак движения определяется булевым реквизитом `Приход`: Истина → ВидДвиженияНакопления.Приход, Ложь → Расход. 🟢
- Период всех движений = `ДатаОплаты` (не `Дата` документа). 🟢
- В `КассовыйДокумент` дополнительно сверяется `Сумма = СуммаКарта + СуммаНаличные` (контроль раскладки оплаты). 🟢
- Фактически проводится ТОЛЬКО регистр `Взаиморасчеты`; гашение конкретных долгов выполняется отдельно — через ТЧ заявки `РаспределениеОплатДолги` (см. Финансы-ГашениеДолгов.md). 🟢
