# Ценообразование — Задачи реконструкции

> Атомарные задачи для повторной реализации модуля «Ценообразование» без доступа к исходному коду. Каждая задача цитирует легаси-источник, имеет критерий готовности и метку доверия 🟢/🟡/🔴. Дополняет `requirements.md` и `design.md`.

## Предпосылки

- [ ] Доступны зависимости из `design.md`: `Catalog.КатегорииНомеров` (модуль «Размещение»), `Catalog.Клиенты`/`КатегорииКлиентов` (модуль «Гости»).
- [ ] Перечисления `КалендарьЦенТипЦены` (БазоваяЦена/ДоплатаЗаДвухместный/ДоплатаЗаЗавтрак) и `КалендарьЦенВидЦены` (ДолгосрочнаяЦена/ТекущаяЦена) определены (`data-dictionary.md`).
- [ ] Решён вопрос magic-date `'20240401'` и судьбы legacy-ветвей (`questions.md` Q-04).
- [ ] Решён вопрос назначения документов `ИзменениеЦены`/`ИзменениеБазовойЦены` (`questions.md` Q-03).

## Предлагаемый порядок

1. Метаданные T-01…T-06 (фундамент; без них логика не компилируется).
2. Каскад цены дня T-07…T-10, затем тариф T-11 (источники цены).
3. Скидки/комиссия/округление T-12…T-15.
4. Расчёт проживания T-16…T-18 (зависит от 2–3).
5. Запись изменения цен T-20 + исправление T-21.
6. Аналитика/калькулятор T-22…T-24.
7. Оптимизация T-19 — после прохождения тестов TT-01/TT-02 (поведение зафиксировано).

Блокировки: T-16/T-17 блокируются T-07…T-15; T-13 блокируется ответом на Q-05; T-20 блокируется решением по Q-03 (роль документов изменения цен).
