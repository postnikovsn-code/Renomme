# Flowchart — Ежедневный факт-отчёт (ADR / загрузка / выручка)

> `DataProcessors.ЕжедневныйОтчетФакт.Форма` + `CommonModules.ЕжедневныйОтчетФакт`. Доверие 🟢.

```mermaid
flowchart TD
    Start([СформироватьОтчет: ДатаС, ДатаПо]) --> Chk{ПроверкаДаты OK?}
    Chk -- нет --> Warn[Предупреждение, выход]
    Chk -- да --> Calc["ТЗ_ОтчетДанные(ДатаС, ДатаПо)"]

    subgraph Source["Сбор первичных данных"]
        C1["Проживание из ЗаявкаНаБронирование.Проживание<br/>статус Проживает/Выехал/Неустойка,<br/>БонШанс=ЛОЖЬ, ВНУТР.СОЕД. СчетаДетальноДолги"]
        C2[ДопУслуги по заявкам]
        C3[Оплаты: РаспределениеОплатДолги]
        C4["Эквайринг: % по дате установки"]
        C5["КоличествоНомеров = НомернойФонд<br/>(ПометкаУдаления=ЛОЖЬ)"]
        C1 --> C2 --> C3 --> C4 --> C5
    end

    Calc --> Source
    Source --> Fill["ЗаполнитьРегистрЕжедневныйОтчетФакт(ТЗ)<br/>запись в РС ЕжедневныйОтчетФакт"]
    Fill --> Read["Запрос к РС ЕжедневныйОтчетФакт<br/>за период"]
    Read --> Metrics

    subgraph Metrics["Расчёт показателей по строкам"]
        M1["ADRДвухм = Окр(СуммаДвухм/КолДвухм)"]
        M2["ADRОдном = Окр(СуммаОдном/КолОдном)"]
        M3["ЗанятыеНомера = КолОдном + КолДвухм"]
        M4["Загрузка% = Окр(Занятые/КолНомеров*100)"]
        M5["СредСтоимость = Окр(ИтогоСумма/Занятые)"]
        M6["% структуры одно-/двухместных"]
        M1 --> M3 --> M4 --> M5 --> M6
    end

    Metrics --> Out["Вывод областей макета:<br/>Шапка / Строка(день) / Итоги / ИтогиМесяц"]
    Out --> Doc([Табличный документ ПолеОтчета])

    Read -. сводный режим .-> Cons["СформироватьЕжедневныйОтчетСводный:<br/>+ HTTP-данные отелей сети<br/>(Реноме/Лайв/Чехов/ДомСоветов/СтритАрт)"]
```

**Защита:** все деления обёрнуты `Если знаменатель=0 Тогда 0` (🟢).
**Особенность:** отчёт сначала перезаписывает витрину РС `ЕжедневныйОтчетФакт`, потом читает её обратно (🟢).
