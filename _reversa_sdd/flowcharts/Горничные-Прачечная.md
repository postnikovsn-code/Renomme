# Flowchart — Прачечная: деление выручки

`Document.ГорничныеПрачечная/Forms/ФормаДокумента/Module.bsl` → `ОбновитьСуммаПрачечная`. Доверие: 🟢.

```mermaid
flowchart TD
    Старт[Строка ТЧ Прачечная: СуммаОплаты] --> НДС[СуммаНДС = Окр СуммаОплаты * СтавкаНДС / 100+СтавкаНДС]
    НДС --> БезНДС[СуммаБезНДС = СуммаОплаты - СуммаНДС]
    БезНДС --> Отель[СуммаОтелю = Окр СуммаБезНДС * ПроцентОтеля/100]
    БезНДС --> Горничной[СуммаПрачечная к выдаче = Окр СуммаБезНДС * 1 - ПроцентОтеля/100]
    Отель --> Итог[Итоги документа]
    Горничной --> Итог
    Итог --> Зарплата[Σ СуммаПрачечная попадает в зарплату горничной\nполе СуммаПрачечная_И]
```

## Примечания
- 🟢 `ПроцентОтеля` по умолчанию = 10 (`ПриСозданииНаСервере`).
- 🔴 Источник `СтавкаНДСЧисло` не разобран (вероятно настройка финмодуля).
