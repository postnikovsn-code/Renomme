# Flowchart — Перерасчёт себестоимости минибара (средневзвешенная)

Файлы: `ПСН_РЕНОМЕ__АУДИТ/src/DataProcessors/Минибар/Forms/Форма/Module.bsl` — `ОбновитьСебестоимостьМиниБара` (808), `ДатыОбновления` (839), `БудущиеДаты` (891), `ОбновитьСебестоимостьМиниБараНаСервере` (968). Доверие: 🟢.

```mermaid
flowchart TD
    Старт([ОбновитьСебестоимостьМиниБара\nкоманда]) --> Пров{ДатаРасчета\nзаполнена?}
    Пров -->|нет| Выход([выход])
    Пров -->|да| Будущие[БудущиеДаты:\nмесяцы с движениями\nпосле даты расчёта]
    Будущие --> Вопрос[ВопросАсинх:\nподтверждение диапазона]
    Вопрос -->|Отмена| Выход
    Вопрос -->|ОК| Диапазон

    Диапазон["ДатыОбновления():\nнайти первый разрыв в помесячной\nцепочке МинибарСебестоимость;\nот него до ДатаРасчета + будущие месяцы"] --> ЦиклМес

    ЦиклМес[Для каждого месяца Дата_П] --> Расчёт

    subgraph Расчёт["ОбновитьСебестоимостьМиниБараНаСервере(Дата_П)"]
        Начало["Срез последних МинибарСебестоимость\n(КоличествоНачало, СуммаНачало)"] --> Приходы[СУММА прихода за месяц\nиз МинибарПриход.Приход]
        Приходы --> Расходы[СУММА расхода за месяц\nиз МинибарРасход.Расход]
        Расходы --> ЦиклНом[Для каждой номенклатуры]
        ЦиклНом --> Есть{есть движение?\nНачало/Приход/Расход <> 0}
        Есть -->|нет| СледНом[след. номенклатура]
        Есть -->|да| Цена["ЦенаСписания =\n(СуммаНачало+СуммаПриход) /\n(КоличествоНачало+КоличествоПриход)\n(fallback при делении на 0)"]
        Цена --> Итог["СуммаКонец = СуммаНачало+СуммаПриход\n - КоличествоРасход*ЦенаСписания\nКоличествоКонец = Нач+Приход-Расход"]
        Итог --> Запись["Запись МинибарСебестоимость\nПериод = КонецМесяца + 1\n(= начало след. месяца)"]
        Запись --> СледНом
        СледНом --> ЦиклНом
    end

    Расчёт --> ЦиклМес
    ЦиклМес -->|месяцы кончились| Готово([Предупреждение:\nостатки обновлены])
```

## Замечания
- 🟢 Метод оценки — **средневзвешенная** цена по остатку начала месяца + приходу месяца (не FIFO; FIFO применяется только для движений `МинибарПартии` при проведении расхода).
- 🟢 Результат пишется на **начало следующего месяца** (`Период = КонецМесяца + 1`), формируя переходящий остаток для следующего расчётного периода.
- 🟢 `ДатыОбновления` обеспечивает пересчёт цепочки месяцев от первого разрыва — защита от «дыр» в помесячной непрерывности.
- 🟡 Списание считается через `КоличествоРасход` без разделения на продажу/списание (флаг `Списание` здесь не учитывается; разделение применяется в отчёте «Прибыль»).
