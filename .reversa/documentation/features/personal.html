Персонал и зарплата

Как устроена фича · модуль «Персонал и зарплата» 23 210 строк сложность: высокая

Модуль ведёт кадровый учёт администраторов стойки и расчёт их зарплаты за период: сдельные ставки по сменам (12/24ч), оклад постоянных пропорционально расчётным дням, надбавки за стаж/стандарты/языки, переработки, доплаты за проживающих и за заселения/завтраки по внешним базам сети, премии, больничные, отпускные, авансы и итог к выплате. Зарплата горничных — отдельный модуль.

Назначение

Ведёт карточку администратора ресепшн, должности и историю ставок/окладов.

Рассчитывает зарплату администраторов за период по сменам с многочисленными надбавками и доплатами.

Тянет данные о заселениях/завтраках из внешних баз сети для доплат, ветвясь по имени отеля.

Бизнес-правила

  • HR-01Оклад за смену по длине смены: 0 при нулевой длине; Окр(Ст12×ДлС/12) до 12ч; Окр(Ст24×ДлС/24) до 24ч; Ст24 сверх.
  • HR-02Номера смен: 0 (нет), 1 (день, 09:00), 2 (ночь, 21:00), 3 (отпуск), 4 (особая для постоянных, 8ч).
  • HR-03Расчётные дни = (ДК-ДН+1) - ДниОтпуска; оклад постоянного = Окр(Оклад × РасчДней / ДнейМесяца).
  • HR-04Надбавка за стаж = 0, если ДатаПриема пуста или установлен НеНачислятьЗаСтаж.
  • HR-05Доплата за проживающих — бэнд РС по числу номеров на длину смены; деление между админами смены закомментировано — вся сумма идёт одному.
  • HR-06Источники заселений/завтраков ветвятся по имени отеля («Реноме» в Лайв, «Чехов» в ДомСоветов плюс СтритАрт) — хардкод.
  • HR-07Документ ЗП администраторов не проводится по регистрам — данные в ТЧ, отчётность прямым запросом (нет единого источника правды).

Крайние случаи

  • Форма создаёт около 30+ динамических реквизитов вида Оклад_ddMMyy по каждому дню месяца — в метаданных их нет.
  • Расчёт отпускных по СтавкаЗаОтпуск в коде расчёта однозначно не локализован.
  • Деление суммы за проживающих между администраторами одной смены закомментировано.
  • В смежном коде встречается КоличествоЧасовНаКлиенте с множителем 8 вместо ДлинаСмены (тот же баг, что у горничных).

Открытые вопросы

  • 🔴 Q-01Динамические реквизиты формы *_ddMMyy не каталогизированы поимённо — нужен полный список показателей дня и типов.
  • 🔴 Q-02Расчёт отпускных (СтавкаЗаОтпуск) не локализован — формула и место применения.
  • 🔴 Q-03Деление суммы за проживающих между администраторами смены закомментировано — намеренно или незавершено.
  • 🔴 Q-04РС АдминистраторыТабель объявлен, но не используется — мёртвая сущность или будущая интеграция.
  • 🔴 Q-05Дубли-версии *_Версия — подтвердить, что переносить только основные объекты.
  • 🔴 Q-06Хардкод имён отелей в ветвлении источников заселений — нужна конфигурируемая таблица.
