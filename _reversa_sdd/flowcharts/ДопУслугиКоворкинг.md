# Flowchart модуля: Доп. услуги и коворкинг

Домен охватывает два связанных контура:

1. **Доп. услуги гостю** — справочник `ДопУслуги` (прайс/каталог платных услуг, частично зеркало номенклатуры минибара), документ `СписаниеДопУслуг` (массовое создание оплат-списаний долга за допуслуги по броням).
2. **Коворкинг** — заявки на аренду рабочих мест (`КоворкингЗаявка`), счета по заявкам (`КоворкингСчета`), проверка/резервирование занятости (`РегистрСведений.ЗанятостьНомеровКоворкинг`), рабочее место оператора (`КоворкингЗаявкаОбработка`) и визуальная шахматка (`КоворкингШахматка`).

> Финансовые взаиморасчёты (документы оплаты `КассовыйДокумент`/`ВыпискаБанка`, регистры `Деньги`/`Долги`/`Взаиморасчеты`, `ПрочиеОплаты`, `ОплатыОбщееСервер`, `ЗаявкаСервер`) и контур долгов брони (`ЗаявкаНаБронирование.СчетаДетально*`) принадлежат модулю «Финансы и касса» — здесь они показаны как связи.

```mermaid
flowchart TD
    subgraph Допуслуги["Доп. услуги гостю"]
        Cat[Справочник ДопУслуги<br/>прайс, Товар, НоменклатураМинибара,<br/>ПрограммныйКод, ТуристическийНалог, ЕстьНДС]
        Зеркало[(Зеркало номенклатуры минибара<br/>модуль Минибар)]
        ТЧДоп[ТЧ ЗаявкаНаБронирование.ДопУслуги<br/>модуль Финансы/Бронирование]
        Спис[Документ СписаниеДопУслуг<br/>массовое закрытие долга]
        Спис -->|ОплатыОбщееСервер.СоздатьПрочиеОплатыСписание<br/>ВидОперации=СписаниеДопУслуг| Опл[(ПрочиеОплаты / Долги<br/>Финансы)]
        Спис -->|ЗаявкаСервер.РаспределитьСтрокаОплаты...| ТЧДоп
        Зеркало -.номенклатура.-> Cat
        Cat --> ТЧДоп
    end

    subgraph Коворкинг["Коворкинг"]
        Зв[Документ КоворкингЗаявка<br/>Клиент, Номер, ДатаС/По, ПериодАренды,<br/>Почасовая, ЧасС/По, Цена]
        Сч[Документ КоворкингСчета<br/>период, Цена, Кол-во, Сумма,<br/>ТЧ ДопУслугиКоворкинг/ДокументыОплаты/РаспределениеОплат]
        РС[(РС ЗанятостьНомеровКоворкинг<br/>Номер x ПериодРезерва(час) x Регистратор)]
        Опер[Обработка КоворкингЗаявкаОбработка<br/>дерево номеров → заявки → счета → оплаты]
        Шах[Обработка КоворкингШахматка<br/>визуализация дни/часы]

        Опер -->|ДобавитьСчетЧасы / ДобавитьСчетДни| Сч
        Зв -->|ОбработкаПроведения<br/>почасовое/посуточное| РС
        Сч -->|ОбработкаПроведения<br/>почасовое/посуточное| РС
        Зв -->|КоворкингСервер.ЗанятостьНомераКоворкингПроверить| РС
        Сч -->|проверка занятости| РС
        Сч -->|ДобавитьДокументОплатаКоворкингСчет| ОплК[(КассовыйДокумент/ВыпискаБанка<br/>Финансы)]
        Шах --> РС
        Опер --> Зв
    end

    КС[ОбщийМодуль КоворкингСервер<br/>ядро бизнес-логики]
    КП[ОбщийМодуль КоворкингПечатьСервер<br/>счета/акты/счёт-фактура]
    Зв --- КС
    Сч --- КС
    Опер --- КС
    Сч --- КП
```

## Точки входа

| Точка входа | Файл | Триггер |
|---|---|---|
| Проведение заявки коворкинга | `Documents/КоворкингЗаявка/ObjectModule.bsl:ОбработкаПроведения` | запись/проведение заявки |
| Проведение счёта коворкинга | `Documents/КоворкингСчета/ObjectModule.bsl:ОбработкаПроведения` | запись/проведение счёта |
| Создание счетов из заявки | `DataProcessors/КоворкингЗаявкаОбработка/Forms/Форма/Module.bsl:ДобавитьСчет` → `КоворкингСервер.ДобавитьСчетЧасы/ДобавитьСчетДни` | команда «Добавить счёт» |
| Массовое списание допуслуг | `Documents/СписаниеДопУслуг/Forms/ФормаДокумента/Module.bsl:СоздатьДокументыСписания` | команда «Создать документы списания» |
| Шахматка коворкинга | `DataProcessors/КоворкингШахматка/Forms/Форма/Module.bsl:ВывестиШахматкуДни/ВывестиШахматкуЧасы` | открытие/обновление формы |
