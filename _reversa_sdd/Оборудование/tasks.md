# Подключаемое оборудование (БПО) — Задачи реализации

> Атомарные задачи **интеграции домена с библиотекой БПО**, с цитатой легаси.
> ⚠️ Типовая библиотека БПО ред. 3.2 НЕ переписывается — переиспользуется как зависимость.
> Реализуются только доменные обёртки и точки интеграции.
> Шкала: 🟢 подтверждено · 🟡 выведено · 🔴 пробел.

## Pré-requisitos

- [ ] Подключена типовая БПО ред. 3.2 (подсистема `ПоддержкаОборудования`) как родительская библиотека / зависимость. 🟢
- [ ] Доступны фасады `МенеджерОборудования*`, `ОборудованиеЧекопечатающиеУстройства*`, `РаспределеннаяФискализация*`, `РассылкаЭлектронныхЧеков*`. 🟢
- [ ] Настроены `Catalog.РабочиеМеста`, `SessionParameter.РабочееМестоКлиента`. 🟢
- [ ] Заданы константы сроков хранения журналов операций. 🟢
- [ ] (для Сервера ККМ) Доступен внешний HTTP-сервис АТОЛ, известны Адрес/Порт/ИдУстройства/креды. 🔴 (Q-01)
