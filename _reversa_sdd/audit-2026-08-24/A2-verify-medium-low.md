### M1 — Лист ожидания: маппинг времени выезда расходится с каноном → **ЗАКРЫТ ЧАСТИЧНО**

Документ переименован в `ЛистОжидания_НеИспользуется` и выведен из эксплуатации, **код не исправлен**.

`Documents/ЛистОжидания_НеИспользуется/Forms/ФормаДокумента/Module.bsl`
(`Функция ПеревестиВБроньНаСервере` `:23` … `КонецФункции` — обе границы проверены):

```
:37  Выезд=0;
:38  Если Объект.ВремяВыезда=Перечисления.ВремяВыезда.Вр0 тогда
:39  	Выезд=0;                 <-- канон: 24
:42  иначеесли Объект.ВремяВыезда=Перечисления.ВремяВыезда.Вр12 тогда
:43  	//Выезд=12;
:44  	Выезд=14;                <-- канон: 12
```

Канон — `CommonModules/ДокументыСервер/Module.bsl`, `Функция ЗанятостьНомераПериодРезерва` (`:231` … `:262`):
`:245–247` `Вр0 → //Выезд=0; Выезд=24;`, `:250–252` `Вр12 → //Выезд=14; Выезд=12;`.
То есть **канон правился в обратную сторону**, а форма листа ожидания осталась в старом варианте.

Почему дефект недостижим: сплошной поиск строки `ЛистОжидания_НеИспользуется` по всему дереву даёт
4 файла — `Configuration/Configuration.mdo:603` и три собственных файла документа. Ни одна роль,
подсистема, команда или строка BSL на него не ссылается. Кнопка «Лист ожидания» интерфейса
(`DataProcessors/Интерфейс/Forms/Форма/Module.bsl:1538–1543`) открывает
`Документ.ЗаявкаНаБронирование.ФормаСписка` с параметром `Новый Структура("ЛистОжидания", Истина)` —
контур переведён на булев реквизит `ЗаявкаНаБронирование.ЛистОжидания`
(`ЗаявкаНаБронирование.mdo:691`).

**Остаток:** документ остаётся зарегистрирован в конфигурации; при возврате его в работу дефект
воскреснет вместе с M2 (тот же модуль).
🟢 ПОДТВЕРЖДЕНО

### M2 — Подбор свободных номеров: `МЕЖДУ` без `−1` и без исключения своего регистратора → **ОТКРЫТ**

Живая половина пункта — `Documents/ЗаявкаНаБронирование/Forms/ФормаДокумента/Module.bsl`,
`Функция АвтоНаСервере()` `:5177` … `:5230` (обе границы проверены):

```
:5178  Ответ = ДокументыСервер.ЗанятостьНомераПериодРезерва(...);   <-- маппинг времени унифицирован
:5195  |  ЗанятостьНомеров.ПериодРезерва МЕЖДУ &ПериодН И &ПериодК))";
:5200  ЗапросСвободных.УстановитьПараметр("ПериодН",ТемпС);
:5201  ЗапросСвободных.УстановитьПараметр("ПериодК",ТемпПо);        <-- без «- 1»
```

Эталон — `ДокументыСервер:293` `УстановитьПараметр("ПериодК", КонецПериодаРезерва - 1)` и
`:280` `И ЗанятостьНомеров.Регистратор <> &Регистратор`. В `АвтоНаСервере` нет ни `−1`,
ни отбора по регистратору.

Мёртвая половина (`ЛистОжидания_НеИспользуется/…:64`, `:66–67`) — та же ошибка, но контур выведен (см. M1).

**Воспроизведение:** бронь A выезд 12.03 (Вр12 → 12:00), бронь B заезд 12.03 (Вр14 → 14:00).
`ПериодК` для B = 12.03 12:00 включительно → запись занятости A на 12.03 12:00 попадает в интервал,
