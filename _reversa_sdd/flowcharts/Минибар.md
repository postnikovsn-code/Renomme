# Flowchart — Модуль «Минибар»

Уровень: detalhado. Доверие: 🟢 подтверждено / 🟡 выведено.

> Два контура: **Минибар** (`НоменклатураМиниБара` → `МинибарОстатки`/`МинибарПартии`/`МинибарСебестоимость`) и **«Бар»/Товары** (`Товары` → `ОстаткиПродукции`/`СебестоимостьТоваров`, документ `ИнвентарицацияБара`).

## Общий поток модуля

```mermaid
flowchart TD
    subgraph Горничные["Модуль Горничные"]
        Уборка[Документ ГорничныеОбслуживаниеНомера\nТЧ Минибар: товар/кол-во/цена]
    end

    subgraph МинибарКонтур["Контур Минибар (НоменклатураМиниБара)"]
        Приход[Документ МинибарПриход\nОбработкаПроведения]
        Расход[Документ МинибарРасход\nОбработкаПроведения - FIFO]
        Обработка[DataProcessor Минибар]

        Приход -->|+приход| РОстатки[(РН МинибарОстатки)]
        Приход -->|создать партию| РПартии[(РН МинибарПартии)]

        Уборка -->|СоздатьДокументРасходНаСервере\nПрограммно=Истина| Расход
        Обработка -.управляет.-> Расход

        Расход -->|-расход| РОстатки
        Расход -->|FIFO-списание партий| РПартии

        Обработка -->|ОбновитьСебестоимость| РСеб[(РС МинибарСебестоимость\nпериод=Месяц, средневзв.)]
        Приход --> РСеб
        Расход --> РСеб

        Обработка -->|ОтчётМесяц / Прибыль| Отчёты[ТабличныеДокументы\nДвижение / Прибыль]
    end

    subgraph БарКонтур["Контур Бар (Catalog.Товары)"]
        Инв[Документ ИнвентарицацияБара\nРасхождение=Факт-Учёт]
        Инв -->|+/- расхождение| РОстПрод[(РН ОстаткиПродукции)]
        РОстПрод -->|заполнение ТЧ| Инв
        РСебТов[(РС СебестоимостьТоваров)] -->|заполнение ТЧ| Инв
    end

    subgraph ДопУслуги["Модуль Доп.услуги"]
        Номенклатура[Catalog.НоменклатураМиниБара\nПриЗаписи]
        Номенклатура -->|ОбновитьДопУслуги: зеркало| Услуга[Справочник ДопУслуги\nгруппа Минибар]
        Номенклатура -.ОбменСГорничными.-> БДГ[(БД Горничные COM)]
    end
```

## Ключевые правила (резюме)
- 🟢 Приход создаёт партию на каждый документ (`МинибарПартии`, ключ = документ прихода).
- 🟢 Расход списывает партии по FIFO (порядок = дата прихода), цена партии = `ЦенаПриход`.
- 🔴 При нехватке партий — движение без партии (себестоимость 0), «торговля в минус».
- 🟢 Расход обычно формируется автоматически из уборок (`Программно=Истина`, идемпотентно за месяц).
- 🟢 Себестоимость — средневзвешенная, помесячный перенос остатков в `МинибарСебестоимость`.
- 🟢 Инвентаризация бара (контур `Товары`/`ОстаткиПродукции`) = Факт − Учёт.
- 🟢 Номенклатура минибара зеркалируется в `ДопУслуги` (продажа гостю) и в БД горничных.
