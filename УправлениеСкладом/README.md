# Управление складом — проект для 1С:EDT

Демонстрационная конфигурация «Управление складом» для платформы
«1С:Предприятие 8.3» в формате файлов 1C:EDT (управляемое приложение).

## Возможности

- Справочники: «Номенклатура», «Склады», «Контрагенты»
- Документы: «Приходная накладная», «Расходная накладная»
- Регистр накопления «Остатки товаров» (вид — остатки)
- Отчет «Остатки товаров» на СКД с группировкой по складам
- Общие модули: «СкладСервер» (логика) и «СкладПовтИсп» (повт. использование)
- Контроль остатков при проведении расходной накладной
- Автозаполнение демонстрационных данных при первом запуске

## Структура проекта (формат EDT)

```
УправлениеСкладом/
├─ .project
├─ README.md
├─ .settings/
│  └─ org.eclipse.core.resources.prefs
└─ src/
   ├─ Configuration/            — корневой объект конфигурации
   ├─ Languages/                — язык «Русский»
   ├─ Subsystems/               — подсистема «Управление складом»
   ├─ Catalogs/                 — Номенклатура, Склады, Контрагенты
   ├─ Documents/                — ПриходнаяНакладная, РасходнаяНакладная
   ├─ AccumulationRegisters/    — ОстаткиТоваров
   ├─ CommonModules/            — СкладСервер, СкладПовтИсп
   └─ Reports/                  — ОстаткиТоваров (СКД)
```

## Импорт в 1C:EDT

1. Скопируйте папку проекта (с файлом `.project` и каталогом `src`)
   в удобное место на диске.
2. В EDT выполните **File → Import… → General → Existing Projects into Workspace**
   и укажите корневую папку проекта.
   Альтернатива: **File → Import… → 1C:Enterprise → 1C:Enterprise configuration files**
   с указанием каталога `src`.
3. Дождитесь окончания индексации и сборки: **Project → Build All**.
4. Запустите приложение: **Run → Run As → 1C:Enterprise Managed Application**,
   выбрав (или создав) файловую информационную базу.

## Примечания

- Формы не переопределены — используются типовые формы платформы,
  поэтому конфигурация полностью работоспособна сразу после импорта.
- Режим совместимости: «Версия 8.3.21».
- При первом запуске процедура `СкладСервер.ЗаполнитьДемоДанные()` создаст
  два склада, номенклатуру, контрагентов и проведет приходные накладные.
