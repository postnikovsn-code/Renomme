# Flowchart — Модуль «Горничные (Housekeeping)»

Уровень: detalhado. Доверие: 🟢 подтверждено / 🟡 выведено.

## Общий поток модуля

```mermaid
flowchart TD
    subgraph ВнешняяБД["Отдельная база 1С «Горничные» (планшеты)"]
        GДанные[(Уборки / Смены / Помещения)]
    end

    subgraph Отель["База «ОТЕЛЬ»"]
        Бронь[Проведение/изменение брони] -->|ОбменГорничныеСервер.СоздатьЗаявку| GДанные
        ТумблерСоздать{Константа\nОбменСГорничными?}
        Бронь --> ТумблерСоздать
        ТумблерСоздать -- Ложь --> X1[выход]

        Загрузка[DataProcessor.ЗагрузкаГорничные\nили форма Зарплаты] -->|ЗагрузитьОбслуживаниеНомеров/Помещений/Смены| GДанные
        GДанные -->|COM ТЗ| ДокУборка[Документ\nГорничныеОбслуживаниеНомера]
        ДокУборка -->|РучноеИзменение? пропуск| ДокУборка
        ДокУборка -->|ОбработкаПроведения| РСУборки[(РС УборкиНомеров)]

        ДокПом[Документ\nГорничныеОбслуживаниеПомещения]
        ДокСмены[Документ\nГорничныеСмены]
        ДокПрачка[Документ\nГорничныеПрачечная]

        Прайс[Catalog.ГорничныеСтоимостьУборок] --> Зарплата
        Шкала[(РС ГорничныеНадбавкаЗаСтаж)] --> Зарплата
        РСУборки --> Зарплата[Документ ГорничныеЗарплата\nРасчитатьЗарплатуНаСервере]
        ДокПом --> Зарплата
        ДокСмены --> Зарплата
        ДокПрачка --> Зарплата
        Зарплата --> Квиток[Документ ГорничныеОбщийКвиток / Отчёты]

        КаталогГ[Catalog.Горничные] -->|ПриЗаписи: ОбновитьГорничнаяГорничные| GДанные
        GДанные -->|ОбновитьГорничныеОтель и др.| КаталогГ
    end
```

## Ключевые правила (резюме)
- 🟢 Обмен с БД горничных управляется `Константа.ОбменСГорничными`.
- 🟢 Уборки регистрируются в БД горничных, в «ОТЕЛЬ» загружаются и проводятся в РС `УборкиНомеров`.
- 🟢 Зарплата: модель И/Р/Э/Есть; сдельная часть только при `Горничная.УчетУборок`.
- 🟢 Прачечная: выручка делится после извлечения НДС по `ПроцентОтеля`.
