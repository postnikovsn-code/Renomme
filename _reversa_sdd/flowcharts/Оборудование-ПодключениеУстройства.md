# Сценарий — Подключение устройства / драйвера (БПО)

> Источник: `CommonModules/ФУ_Клиент/Module.bsl` (`ПриОткрытии_Подключить`,
> `ВыполнитьПодключитьОтключитьОборудование`), вызовы `МенеджерОборудованияКлиент.*`,
> `DataProcessor.АТОЛ10106` (`ДобавитьДрайверНаСервере`).
> 🟡 Внутренние шаги загрузки внешней компоненты драйвера — внутри библиотеки БПО, не разбирались.

```mermaid
flowchart TD
  Start([Открытие формы кассы / запуск РМ]) --> Onopen["ФУ_Клиент.ПриОткрытии_Подключить(Форма)"]
  Onopen --> RM["МенеджерОборудованияКлиентПовтИсп.РабочееМестоКлиента()<br/>(SessionParameter.РабочееМестоКлиента)"]
  RM --> ByType["МенеджерОборудованияКлиент.<br/>НачатьПодключениеОборудованиеПоТипу(...)"]
  ByType --> Drv["Библиотека: чтение Catalog.ПодключаемоеОборудование +<br/>Catalog.ДрайверыОборудования для РМ"]
  Drv --> Comp["ВнешниеКомпонентыБПОКлиент:<br/>установка/загрузка внешней компоненты драйвера"]
  Comp --> OK{Подключено?}
  OK -->|Да| Ready["Устройство активно на форме<br/>(идентификатор объекта запомнен)"]
  OK -->|Нет| Err["Сообщение пользователю +<br/>запись РС ОперацииСПодключаемымОборудованием"]

  subgraph SETUP["Регистрация нового драйвера (АТОЛ10106)"]
    A1["АТОЛ10106.ДобавитьДрайвер (команда)"] --> A2["ДобавитьДрайверНаСервере()<br/>создаёт/настраивает Catalog.ДрайверыОборудования"]
  end

  Close([Закрытие формы]) --> Off["ФУ_Клиент.ПриЗакрытии_Отключить(Форма)"]
  Off --> OffLib["МенеджерОборудованияКлиент.НачатьОтключениеОборудованияПоТипу(...)"]
```

**Ключевые точки (🟢):**
- Привязка «устройство → рабочее место» через `Catalog.РабочиеМеста` + `SessionParameter.РабочееМестоКлиента`.
- Подключение/отключение — асинхронные вызовы `МенеджерОборудованияКлиент.Начать…ПоТипу` (callback-стиль).
- Драйвер физически — внешняя компонента, поставляемая `CommonTemplate.Драйвер…` (63 шаблона драйверов).
