# Flowchart функции: закрытие финансового периода

> `DataProcessors/ЗакрытиеФинансовогоПериода/ManagerModule.bsl` (ЗаполнитьОтчетДолгиНаСервере) 🟢
> `DataProcessors/ЗакрытиеФинансовогоПериода/Forms/Форма/Module.bsl:18-392` 🟢
> Это отчёт-сверка (не проводящий документ): строит «Долги к закрытию» и «Списания».

```mermaid
flowchart TD
    A["Заполнить(Команда)"] --> B["ЗаполнитьОтчетДолгиНаСервере(ДатаС, ДатаПо)"]
    A --> C["ЗаполнитьОтчетСписаниеНаСервере(ДатаС, ДатаПо)"]

    B --> D["Запрос: ЗаявкаНаБронирование<br/>ПометкаУдаления=Ложь<br/>Статус ∈ {Выехал, Неустойка}<br/>РезервПо ∈ [ДатаС; ДатаПо]"]
    D --> E["Левые соединения по ТЧ заявки:<br/>Проживание (Σ Сумма)<br/>ДопУслуги ВСчет=Истина (Σ Кол·Цена)<br/>СчетаДетальноДолги Услуга=Ложь/Истина (СуммаДолг, СуммаКЗакрытию)<br/>РаспределениеОплатДолги (списания по ВидОперации)"]
    E --> F["Фильтр отчёта «Долги»:<br/>СуммаКЗакрытию (прож+услуги) > 0"]
    F --> G["Подсветка: СуммаПроживаниеСчета ≠ СуммаПроживание → красный"]
    G --> H["Итог СуммаДолга; счётчик полностью закрытых заявок (СуммаКЗакрытию=0)"]

    C --> I["Тот же запрос + фильтр:<br/>есть СуммаОплаты по ВидОперации ∈<br/>{Списание, СписаниеЗачет, СписаниеДопУслуг}"]
    I --> J["Разбивка списаний доп.услуг:<br/>ВерхняяПапка(Услуга) → ПрограммныйКодУслуги"]
    J --> K{"ПрограммныйКод"}
    K -->|"МИНИБАР"| K1["СуммаМинибар += СуммаОплаты"]
    K -->|"ПРАЧЕЧНАЯ"| K2["СуммаПрачечная += СуммаОплаты"]
    K -->|"прочее"| K3["в общую СуммаДопУслуг"]
    K1 & K2 & K3 --> L["Вывод ИтогиУслуги в табличный документ"]
```

## Ключевые правила
- В закрытие попадают только заявки со статусом `Выехал` или `Неустойка` с датой выезда (`РезервПо`) внутри периода. 🟢
- «Долг к закрытию» = `Σ СчетаДетальноДолги.СуммаКЗакрытию` (проживание + услуги) > 0. 🟢
- «Списание» классифицируется по `ВидыОпераций` документа `ПрочиеОплаты`: Списание / СписаниеЗачет / СписаниеДопУслуг. 🟢
- Списания доп.услуг агрегируются по `ПрограммныйКодУслуги` родительской папки услуги (МИНИБАР / ПРАЧЕЧНАЯ). 🟢
- `ЗакрытиеДокументов` — отдельная обработка: помечает заявки `Закрыто=Истина` за месяц при условии «месяц закрытия < текущий месяц». 🟢
- `ЗакрытьСмену` — фискальное закрытие смены через `ФУ_Клиент.ЗакрытьСмену` (фактическая логика в модуле БПО/фискального оборудования). 🟢
