# Персонал и зарплата (администраторы), Задачи реализации

> Файл `tasks.md` — атомарная последовательность для переподнятия модуля из легаси. Каждая задача цитирует источник, имеет критерий готовности и уровень доверия 🟢/🟡/🔴.
> Зарплата горничных вне области (модуль «Горничные»).

## Предусловия

- [ ] Зависимости из `design.md` доступны: источники проживающих (Бронирование/Ценообразование), HTTP-загрузка заселений (Интеграции).
- [ ] Схема данных совместима: `Catalog.Администраторы` (+ТЧ `Начисления`), `Document.АдминистраторыЗарплата` (ТЧ `Зарплата`, `ЗарплатаСмены`), РС `АдминистраторыНадбавкаЗаСтаж`, `АдминистраторыСуммаЗаПроживающих`.
- [ ] Справочники `Должности`, `ТипыДолжностей` заведены.

  - Критерий готовности: должность выбирается в карточке администратора; тип группирует должности
  - Доверие: 🟢

- [ ] T-02. Создать `Catalog.Администраторы` с реквизитами (Пользователь, ДатаПриема, Должность, Постоянный, НеНачислятьЗаСтаж, НеРаботает, Сортировка, коды Лайв/ДомСоветов/СтритАрт) и ТЧ `Начисления`
  - Источник: `ПСН_РЕНОМЕ__АУДИТ/src/Catalogs/Администраторы/Администраторы.mdo`; словарь — `data-dictionary.md`

- [ ] T-03. Реализовать выбор актуальной строки `Начисления` по `ДатаУстановки ≤ ДК` (последняя)

1. Данные сначала: T-01 → T-02 → T-04 → T-05 (справочники, РС, документ).
2. Заполнение контекста: T-03, T-06, T-07, T-08, T-09, T-10.

- Деление суммы за проживающих между администраторами смены — закомментировано (`:2966-2973`), требует решения.
