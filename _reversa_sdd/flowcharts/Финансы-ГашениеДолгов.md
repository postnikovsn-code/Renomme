# Flowchart функции: гашение долгов (FIFO-распределение оплаты)

> `CommonModules/ЗаявкаОбщееКлиентСервер/Module.bsl:23-100` 🟢
> Ядро: `РаспределитьОплатаСтрокаДолгСтрока` → `РаспределитьОплатаНаСчетаДетальноДолги`.
> Долги хранятся не в регистре, а в ТЧ заявки `СчетаДетальноДолги`
> (СуммаДолг, СуммаКЗакрытию, СуммаОплачено) с ключами СчетГУИД / ДолгиГУИД.

## Распределение одной оплаты на одну строку долга

```mermaid
flowchart TD
    A["РаспределитьОплатаСтрокаДолгСтрока<br/>(ОплатыСтрока, ОстатокКРаспределению, ДолгСтрока, РаспределениеОплатДолги)"] --> B{"ДолгСтрока.СуммаКЗакрытию = 0?"}
    B -->|"Да"| BR["Возврат +1 (строка уже закрыта)"]
    A --> C{"ОстатокКРаспределению = 0?"}
    C -->|"Да"| CR["Возврат -1 (оплата исчерпана)"]
    B -->|"Нет"| D["ОплатыОстаток = ОстатокКРаспределению - СуммаКЗакрытию"]
    D --> E{"ОплатыОстаток > 0?<br/>(оплаты хватает на весь долг строки)"}
    E -->|"Да"| F["СуммаОплаты = СуммаКЗакрытию<br/>ОстатокКРаспределению = ОплатыОстаток<br/>ДолгСтрока.СуммаОплачено = СуммаДолг<br/>ДолгСтрока.СуммаКЗакрытию = 0"]
    E -->|"Нет"| G["СуммаОплаты = ОстатокКРаспределению<br/>СуммаКЗакрытию -= ОстатокКРаспределению<br/>СуммаОплачено += СуммаОплаты<br/>ОстатокКРаспределению = 0"]
    F & G --> H["Найти/создать строку РаспределениеОплатДолги<br/>по (ДокументОплаты, ДолгиГУИД)<br/>СуммаОплаты += СуммаОплаты"]
    H --> I{"Итог"}
    I -->|"СуммаКЗакрытию=0"| I1["Возврат +1"]
    I -->|"ОстатокКРаспределению=0"| I2["Возврат -1"]
    I -->|"иначе"| I3["Возврат 0"]
```

## Гашение долгов через групповой счёт (контрагент-плательщик)

```mermaid
flowchart TD
    A["ГрупповойСчетСервер.РаспределитьДокументОплатыГрупповойСчетОбъект<br/>(ДокументОплаты, ГрупповойСчётОбъект, СуммаОплаты)"] --> B["ОстатокСуммаОплаты = СуммаОплаты"]
    B --> C["Для Каждого Строка Из ГрупповойСчёт.ДокументыДолги"]
    C --> D["ЗаявкаОбъект = Строка.ДокументДолг.ПолучитьОбъект()"]
    D --> E["СуммаСчетаКЗакрытию = Σ СчетаДетальноДолги.СуммаКЗакрытию по СчетГУИД"]
    E --> F{"СуммаСчетаКЗакрытию = 0?"}
    F -->|"Да"| C
    F -->|"Нет"| G["СуммаОплатыЗаявка = Мин(Остаток, СуммаСчетаКЗакрытию)<br/>ОстатокСуммаОплаты -= СуммаСчетаКЗакрытию"]
    G --> H["ДобавитьОплатаСчетаДетальноОплаты + РаспределитьОплатаНаСчетаДетальноДолги<br/>ЗаявкаОбъект.Записать(Проведение)"]
    H --> I{"ОстатокСуммаОплаты <= 0?"}
    I -->|"Да"| J["Прервать → вернуть остаток к распределению"]
    I -->|"Нет"| C
```

## Ключевые правила
- Алгоритм гашения — FIFO по строкам ТЧ `СчетаДетальноДолги`: оплата идёт на строки по порядку, гася `СуммаКЗакрытию` до нуля. 🟢
- Идемпотентность по паре (ДокументОплаты, ДолгиГУИД): повторная оплата накапливается в существующую строку `РаспределениеОплатДолги`, а не дублирует её. 🟢
- Возвращаемые коды-флаги: `+1` строка/долг закрыт, `-1` оплата исчерпана, `0` продолжаем. 🟢
- `ГашениеДолгов_Старая` (`Documents/ГашениеДолгов_Старая/ObjectModule.bsl:2-16`) — устаревший контур, прямо пишет Расход в регистр `Долги` по ТЧ `Долги.СуммаПогашения`; в актуальном контуре долги ведутся в ТЧ заявки, а не в регистре. 🟡
