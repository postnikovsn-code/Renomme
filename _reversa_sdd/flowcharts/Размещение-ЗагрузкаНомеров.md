# Flowchart — Загрузка номеров из внешней базы

> `DataProcessors/ЗагрузкаНомеров{Лайв,Реноме,Чехов}/Forms/Форма/Module.bsl` 🟢
> Три обработки структурно идентичны (различаются строкой COM-подключения). Показан общий поток.

```mermaid
flowchart TD
    A([Команда: ЗагрузитьНомера]) --> B[ПараметрыСоединения<br/>🔴 хардкод File/Usr/Pwd]
    B --> C[Новый COMОбъект V83.COMConnector]
    C --> D{Connect успешен?}
    D -->|Нет| D1[Сообщить ошибку] --> Z([Выход])
    D -->|Да| E[База.NewObject Запрос<br/>ВЫБРАТЬ из Справочник.НомернойФонд<br/>ГДЕ ПометкаУдаления=ЛОЖЬ]
    E --> F[Выполнить.Выгрузить → ТЗ]
    F --> G{Для каждой Строки ТЗ}
    G -->|строка| H[НайтиПоКоду Строка.Код<br/>в локальном НомернойФонд]
    H --> I{Найден?}
    I -->|Да| G
    I -->|Нет| J[СоздатьЭлемент]
    J --> K[Код, Наименование, Этаж,<br/>Курящий, цвета, признаки]
    K --> L[КатегорияНомера =<br/>НайтиПоКоду КатегорияНомера.Код]
    L --> M{КатегорияХостел заполнена?}
    M -->|Да| N[ИмяЗначенияПеречисление база, значение<br/>→ Перечисления.КатегорииХостела имя<br/>в Попытка]
    M -->|Нет| O[Записать]
    N --> O
    O --> G
    G -->|конец| Z

    subgraph Отдельные команды
      P1[ЗагрузитьКатегорииНомеров<br/>создание категорий по коду]
      P2[ЗагрузитьДанныеНомеров<br/>ОбщийКондиционер + ТЧ Соседи<br/>🔴 баг соседей в Лайв/Чехов]
    end
```

## Хелпер `ИмяЗначенияПеречисление(Соединение, Значение)`

```mermaid
flowchart LR
    A([Значение]) --> B{Пустое?}
    B -->|Да| R0[Возврат пустой строки]
    B -->|Нет| C[ИмяПеречисления = Значение.Метаданные.Имя]
    C --> D[НужныйИндекс = Соединение.Перечисления имя .Индекс Значение]
    D --> E[Цикл по ЗначенияПеречисления:<br/>совпал индекс → вернуть .Имя]
    E --> R1[Возврат имени или пустой строки]
```

## Замечания
- 🔴 Строки подключения с паролем захардкожены (`UsingHardcodePath`, `UsingHardcodeSecretInformation`).
- 🔴 `ЗагрузитьДанныеНомеров` в Лайв/Чехов: цикл `Для Каждого ... Из ТЗ.Соседи` (надо `Строка.Соседи`) и присваивание `НоваяСтрокаСоседиСоседнийНомер` без точки → соседи не пишутся. В Реноме исправлено.
- Создание только отсутствующих (идемпотентность по коду); существующие номера не обновляются основной командой. 🟢
