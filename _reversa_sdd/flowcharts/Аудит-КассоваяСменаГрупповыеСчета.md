# Flowchart — Аудит: ОтчетКассоваяСмена, групповые счета

> Добавлено повторным извлечением №1 (коммит `Изменения ПСН`, 2026-06-18).
> Источник: `Reports/ОтчетКассоваяСмена/Forms/ФормаОтчета/Module.bsl`. Доверие 🟢.

Новая ветка отчёта по кассовой смене: для оплат по групповому счёту (`ДокументСсылка.ГрупповыеСчета`) выводится разбивка суммы по корневым группам доп. услуг.

```mermaid
flowchart TD
    A[ТабДокКасса] --> B[Запрос по Документ.КассовыйДокумент<br/>фильтр: НомерСменыККМ, период, ВключатьПроизвольныеЧеки]
    B --> C{Цикл по строкам оплат}
    C --> D{ТипЗнч ДокументДолг = ГрупповыеСчета?}
    D -- Нет --> E[Вывод обычной строки макета<br/>ИтогоПоКарте / Наличные / Возврат / Отель / Коворкинг]
    D -- Да --> F[ТЗ_Данные: УслугаКорень, СуммаОплаты]
    F --> G{Цикл по ДокументДолг.ДокументыДолги}
    G --> H[ТЗ_Заявка ДокументДолг, ДокументОплаты]
    H --> H1[Запрос ЗаявкаНаБронирование.РаспределениеОплатДолги<br/>⟕ ДопУслуги по ДолгиГУИД = ГУИД]
    H1 --> H2[Колонка УслугаКорень:<br/>NULL-услуга → «Проживание»,<br/>иначе КореньУслуга подъём по иерархии]
    H2 --> I[Накопить в ТЗ_Данные]
    G -- конец --> J[Свернуть ТЗ_Данные по УслугаКорень]
    J --> K[ПрисоединитьГруппа:<br/>область «Строка/Группа»<br/>сумма «Проживание», затем по группам доп. услуг]
    K --> L[Групповая сумма → ИтогоОтель]
    E --> M[Подножие: итоги смены]
    L --> M
```

**Примечания**
- `ТЗ_Заявка` и `ПрисоединитьГруппа` — новые функции, выделены из ранее inline-кода. 🟢
- `ТабДокКасса_1` — мёртвый клон старой версии (без обработки `ГрупповыеСчета`), не вызывается. 🟡 кандидат на удаление.
- Отчёт строится вручную через `ТабличныйДокумент` (без СКД); новых параметров СКД нет. 🟢
