# Flowchart — `ОсмотрНомера.ОбработкаПроведения(Отказ, Режим)`

> `Documents/ОсмотрНомера/ObjectModule.bsl:2-28` 🟢
> Формирование движений РС `ЗамечанияПоНомерам`.

```mermaid
flowchart TD
    A([Старт проведения]) --> B{ТЧ Замечания пуста?}
    B -->|Да| C[Добавить 1 движение ЗамечанияПоНомерам]
    C --> C1[Комната ← Комната<br/>ВремяПроверки ← Дата<br/>Комментарий ← Комментарий<br/>Замечание ← Справочники.Замечания.Нет<br/>Супервайзер ← ПостПроверка]
    C1 --> Z([Конец])
    B -->|Нет| D{Для каждого ТекСтрока Из Замечания}
    D -->|строка| E[Добавить движение ЗамечанияПоНомерам]
    E --> E1[Комната ← Комната<br/>ВремяПроверки ← Дата<br/>Комментарий ← Комментарий<br/>Замечание ← ТекСтрока.Замечание<br/>Супервайзер ← ПостПроверка]
    E1 --> D
    D -->|конец цикла| Z
```

## Замечания
- Код сгенерирован «Конструктором движений регистров» (метка `__КОНСТРУКТОР_ДВИЖЕНИЙ_РЕГИСТРОВ`). 🟢
- `registerRecordsDeletion=AutoDelete` — при отмене проведения движения удаляются автоматически. 🟢
- Нет транзакции/обработки исключений — стандартное автопроведение платформы. 🟡
