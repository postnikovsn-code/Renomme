# Flowchart — Бронирование: ЧекАгента

> Добавлено повторным извлечением №1 (коммит `Изменения ПСН`, 2026-06-18).
> Источник: `Documents/ЗаявкаНаБронирование/Forms/ФормаДокумента/Module.bsl`. Доверие 🟢 (прямо из кода).

Печать «Чека агента» в документе `ЗаявкаНаБронирование` — чек ККМ на сумму продажи номера турагентством. Группа доступна только когда контрагент `Бронирует` помечен как турагентство.

```mermaid
flowchart TD
    A[ПриСозданииНаСервере] --> B{Бронирует.Турагентство?}
    B -- Нет --> B0[ГруппаЧекАгенту.Доступность = Ложь]
    B -- Да --> B1[ГруппаЧекАгенту.Доступность = Истина]

    C([Команда ЧекАгента]) --> D[Число суток = Цел РезервПо − РезервС / 86400, минимум 1]
    D --> E[Позиция чека: «Услуги гостиницы N сут.»<br/>Цена = Сумма = ЦенаПродажиАгентом]
    E --> F[СтавкаНДС = ДокументыСервер.СтавкаНДСТекущая<br/>с учётом Организация.ВсеСНДС / СтавкаНДС]
    F --> G[СуммаНДС = ДокументыСервер.СуммаНДС]
    G --> H[ПараметрыФормы:<br/>СуммаКОплате = СуммаПредыдущихОплат = ЦенаПродажиАгентом<br/>ЭтоАванс = Ложь]
    H --> I[ОткрытьФорму ОбщаяФорма.Чек<br/>блокировка интерфейса<br/>оповещение ЗакрытиеФормы_ЧекАгента]
    I --> J{Результат закрытия}
    J -- Неопределено --> K[Выход]
    J -- Иначе --> L[ОчиститьСообщения]
```

**Примечания**
- Движений регистров не порождает: чек печатается через внешнюю общую форму `Чек` (поток ККТ/фискализации см. модуль Финансы). 🟢
- `ЗакрытиеФормы_ЧекАгента` — обработчик-заглушка (без постобработки результата чека). 🟡 возможный пробел: результат печати чека нигде не фиксируется в документе.
