# Flowchart — Расчёт зарплаты горничных

`Document.ГорничныеЗарплата/Forms/ФормаДокумента/Module.bsl` → `РасчитатьЗарплатуДействие` / `РасчитатьЗарплатуНаСервере`. Доверие: 🟢.

```mermaid
flowchart TD
    Старт[Команда РасчитатьЗарплату] --> ЗапСправ[ЗаполнитьСправочныеДанные:\nцены уборок, помещения, горничные, шкала стажа]
    ЗапСправ --> Обмен{ОбменСГорничными\nи ОбновитьДанныеГорничных?}
    Обмен -- да --> Дозагрузка[ЗагрузитьОбслуживаниеНомеров/Помещений/Смены за ДН..ДК]
    Обмен -- нет --> Цены
    Дозагрузка --> Цены[ЗаполнитьЦеныУборки:\nсрез ГорничныеСтоимостьУборок на ДатаНазначенияЦены<=ДН]

    Цены --> ЗапросУборки[Запрос РС УборкиНомеров\nагрегаты Г/Т/ТС/РК/МК/МДМ\nпо ТипУборкиПризнак, ВремяУброки в ДН..ДК]
    Цены --> ЗапросПрачка[Запрос Прачечная: Σ СуммаПрачечная]
    Цены --> ЗапросСмены[Запрос Смены: КОЛИЧЕСТВО РАЗЛИЧНЫЕ ДатаСмены]
    Цены --> ЗапросПом[Запрос ПомещенияУборки: КОЛИЧЕСТВО РАЗЛИЧНЫЕ Ссылка где Обслужено]

    ЗапросУборки --> ЦиклГ
    ЗапросПрачка --> ЦиклГ
    ЗапросСмены --> ЦиклГ
    ЦиклГ[Для каждой горничной справочника] --> Оклад[Оклад_И = Окр Оклад*РасчДни/ДнейМесяца\nРасчДни = ПериодДни - ДниОтпуска]
    Оклад --> Отпуск[Отпуск_И = Окр ДниОтпуска*Отпуск/ВсегоДнейОтпуска]
    Отпуск --> Стаж[НадбавкаСтаж_И: по шкале РазницаВДняхС..По,\nпропорц. периоду]
    Стаж --> Станд[НадбавкаСтандарты_И пропорц. периоду]
    Станд --> Прачка[СуммаПрачечная_И]
    Прачка --> УчётУборок{Горничная.УчетУборок?}
    УчётУборок -- да --> Уборки[Г/Т/ТС/РК/МК/МДМ:\nКол_И из агрегатов, Сумма=Кол*Цена]
    УчётУборок -- нет --> Ручные
    Уборки --> Ручные[Перенос ручных _Р/_Есть из прошлой версии ТЧ,\nкорректировка количеств с учётом разницы]
    Ручные --> Часы[КоличествоЧасов_И = КоличествоСмен * ДлинаСмены]
    Часы --> ЦиклГ

    ЦиклГ --> Помещения[ЗарплатаПомещения:\nКол по помещениям + ручные корректировки]
    Помещения --> Сведение[ОбновитьСтрокаСуммы:\nПоле_Э = Есть?Р:И; Кол_Э = И+Р]
    Сведение --> Итог[ОбновитьЗарплатаИтого:\nИтого = ΣОклад/Отпуск/Надбавки/Уборки/ДопРаботы/Сдельно/Помещения\nЗарплатаИтого += Прачечная_Э\nОстатокКВыдаче = ЗарплатаИтого - выплаты]
    Итог --> Запись[Запись + Проведение документа]
```

## Примечания
- 🟢 Цены — срез последних на `ДН`; шкала стажа — срез на `ДК`.
- 🔴 Баг: клиентский `КоличествоЧасовНаКлиенте` использует `* 8` вместо `ДлинаСмены`.
- 🟡 Реквизиты/колонки по помещениям создаются динамически (`ДобавитьРеквизитыПомещения`).
