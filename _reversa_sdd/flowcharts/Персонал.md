# Flowchart модуля: Персонал и зарплата

> Домен: администраторы стойки (персонал ресепшн), должности, расчёт зарплаты администраторов по сменам/окладу/надбавкам/премиям. Зарплата горничных — отдельный модуль «Горничные».
> Уровень доверия диаграммы: 🟢 ПОДТВЕРЖДЕНО (извлечено из кода `Documents/АдминистраторыЗарплата/Forms/ФормаДокумента/Module.bsl`, `ManagerModule.bsl`, `.mdo`).

## Обзор: жизненный цикл документа «Администраторы зарплата»

```mermaid
flowchart TD
    Start([Открытие/создание документа АдминистраторыЗарплата]) --> Period[Ввод периода: ДН — дата начала, ДК — дата окончания]
    Period --> RefData[ЗаполнитьСправочныеДанные:<br/>выгрузка справочника Администраторы +<br/>актуальная строка ТЧ Начисления по ДатаУстановки ≤ ДК]
    RefData --> Scales[ЗаполнитьСправочныеДанныеПоДНиДКНаСервере:<br/>загрузка шкал РС АдминистраторыНадбавкаЗаСтаж<br/>и РС АдминистраторыСуммаЗаПроживающих на ДК]
    Scales --> Living[ЗаполнитьПроживающие:<br/>запрос проживающих по дням периода →<br/>КоличествоНомеров на каждый день]
    Living --> ExtLoad{Имя отеля?}
    ExtLoad -->|Реноме| Live[ЗагрузитьЗаселенияЛайв_HTTP]
    ExtLoad -->|Чехов| DS[ЗагрузитьЗаселенияДомСоветов_HTTP +<br/>ЗагрузитьЗаселенияСтритАрт_HTTP]
    ExtLoad -->|иначе| Grid
    Live --> Grid[ЗаполнитьЗарплатаСмены:<br/>построение таблицы смен по дням месяца<br/>динамические реквизиты *_DDMMYY]
    DS --> Grid
    Grid --> Calc[РасчитатьЗарплатуНаСервере]
    Calc --> Manual[Ручные корректировки в форме:<br/>пары реквизитов _Р / _Есть]
    Manual --> Save[ПередЗаписью → ЗаполнитьПередЗаписью:<br/>разворот динамических реквизитов в ТЧ Зарплата + ЗарплатаСмены]
    Save --> Posted([Записан/Проведён — без движений регистров])
```

## Поток расчёта `РасчитатьЗарплатуНаСервере`

```mermaid
flowchart TD
    Start([РасчитатьЗарплатуНаСервере]) --> Loop{Для каждой строки ЗарплатаСмены<br/>= один администратор}
    Loop --> DayLoop{Для каждого дня ДН..ДК}
    DayLoop --> ShiftCalc[РасчитатьСтрокаЗарплатаСменыСмена:<br/>формирование строки Часы_DDMMYY =<br/>ДлинаСмены-НомерСмены/Переработка]
    ShiftCalc --> DayLoop
    DayLoop -->|дни кончились| Aggr[ОбновитьСтрокаЗарплатаСменыДаты_Э +<br/>ОбновитьСтрокаЗарплатыСменаИзДат:<br/>суммирование сумм по дням]
    Aggr --> Nadb[РасчитатьНадбавки:<br/>Стаж + Стандарты + ИнЯзыки<br/>пропорц. расчётным дням / дням месяца]
    Nadb --> IsPerm{Администратор.Постоянный?}
    IsPerm -->|Да| Perm[РасчитатьПостоянный:<br/>Оклад и НадбавкаЗаПроживающих<br/>пропорц. КоличествоРасчетныхДней/ДнейМесяца]
    IsPerm -->|Нет| Other
    Perm --> Other[РасчитатьПрочее:<br/>СуммаПрочее = АдминистраторПрочееИтого]
    Other --> Combine[ОбновитьСтрокаЗарплатаСменыОсновные_Э:<br/>выбор И или Р по флагу _Есть]
    Combine --> Totals[ОбновитьЗарплатаСменыИтоги:<br/>ИтогоСмены, Итого, КВыплате]
    Totals --> Loop
    Loop -->|строки кончились| End([Заполнены ТЧ Зарплата и ЗарплатаСмены])
```

## Семантика троек реквизитов И / _Р / _Есть

```mermaid
flowchart LR
    I["Реквизит (И)<br/>= рассчитано системой"] --> Sel{_Есть = Истина?}
    R["Реквизит_Р<br/>= ручная замена"] --> Sel
    Sel -->|Да| UseR[Э = _Р<br/>взять ручное значение]
    Sel -->|Нет| UseI[Э = И<br/>взять расчётное]
    UseR --> Final["Реквизит_Э<br/>= эффективное значение для Итого"]
    UseI --> Final
```

> Примечание: для количественных «заселений/завтраков» правило иное — `_Э = И + _Р` (ручное является **дельтой**, а не заменой). См. `ОбновитьСтрокаЗарплатаСменыОсновные_Э`, строки 2055-2071.

## Связи модуля

```mermaid
flowchart LR
    Pers[Персонал и зарплата] -->|проживающие, статусы броней| Bron[Бронирование]
    Pers -->|КоличествоНомеров за день, тарифы проживания| Price[Ценообразование]
    Pers -->|ЗагрузитьЗаселения*_HTTP из внешних баз| Integr[Интеграции и обмен]
    Pers -.->|общий паттерн сдельной ЗП + надбавка за стаж| House[Горничные]
    Pers -->|Должность администратора| Dolzh[Справочник Должности]
```
