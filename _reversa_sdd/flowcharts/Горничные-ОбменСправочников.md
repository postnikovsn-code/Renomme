# Flowchart — Двусторонний обмен справочниками горничных

`Catalog.Горничные.ObjectModule` + `CommonModule.ОбменГорничныеСервер`. Доверие: 🟢.

```mermaid
flowchart TD
    subgraph Исходящий["ОТЕЛЬ -> БД горничных"]
        Запись[Запись Catalog.Горничные] --> Загрузка{ОбменДанными.Загрузка?}
        Загрузка -- да --> Выход1[выход — пришло из обмена]
        Загрузка -- нет --> GUID{ГорничнаяГУИДСтрока пуст?}
        GUID -- да --> ПрисвоитьGUID[ГорничнаяГУИДСтрока = GUID ссылки\nПроверкаОбмена = Истина]
        GUID -- нет --> ПроверкаИзм[ПроверкаОбмена: изменились\nНаименование/Сортировка/НеРаботает/ПометкаУдаления/УчетУборок?\nи УчетУборок=Истина]
        ПрисвоитьGUID --> ПриЗаписи
        ПроверкаИзм --> ПриЗаписи{ПроверкаОбмена?}
        ПриЗаписи -- да --> Выгрузить[ОбновитьГорничнаяГорничные -> COM в БД горничных]
        ПриЗаписи -- нет --> Конец1[ничего]
        Выгрузить --> Ошибка{Ошибка?}
        Ошибка -- да --> Сообщить[Сообщить «не выгружена»]
    end

    subgraph Входящий["БД горничных -> ОТЕЛЬ"]
        RPC[COM-вызов из БД горничных] --> Обнов[ОбновитьГорничныеОтель /\nОбновитьГорничныеПомещенияОтель /\nОбновитьНоменклатураМиниБараОтель /\nОбновитьКомплектацияОтель]
        Обнов --> ПоискКлюч[Поиск по GUID/коду/ПомещениеГорничные]
        ПоискКлюч --> СоздатьОбновить[Создать или обновить элемент]
        СоздатьОбновить --> ЗагрФлаг[ОбменДанными.Загрузка = Истина\n-> Записать без обратной выгрузки]
    end
```

## Примечания
- 🟢 Флаг `ОбменДанными.Загрузка` разрывает цикл «эхо» обмена.
- 🟢 Синхронизация `ГорничныеНомера` ↔ `НомернойФонд` по `НомерГорничные` — `DataProcessor.ОбновитьГорничныеНомера`.
