# Flowchart — `ГлубинаБронирования.СформироватьНаСервере`

Источник: `DataProcessors/ГлубинаБронирования/Forms/Форма/Module.bsl:22-195`. Доверие: 🟢.

```mermaid
flowchart TD
    Start([Сформировать за период]) --> Cnt[Запрос: КоличествоНомеров<br/>РАЗЛИЧНЫЕ НомернойФонд без пометки]
    Cnt --> DayLoop{По каждому дню<br/>периода}
    DayLoop --> QDay[Запрос заявок дня:<br/>РазностьДат = дни до заезда,<br/>ПроживанияСЗаездомРаньше]
    QDay --> Roll[Свернуть по номеру/ссылке/датам]
    Roll --> RowLoop{По каждой<br/>брони}
    RowLoop --> Early{Заезд раньше<br/>текущей даты?}
    Early -- да --> CntEarly[ПроживанияЗаездРаньше++]
    Early -- нет --> Bucket[Корзина по РазностьДат:<br/>0-1, 2-3, 4-7, 8-14,<br/>15-30, 31-60, &gt;60]
    CntEarly --> RowLoop
    Bucket --> RowLoop
    RowLoop -- конец --> Forecast[ПрогнозЗагрузки =<br/>Окр ИтогоНомеров / КоличествоНомеров * 100]
    Forecast --> Events[Запрос Мероприятий на дату]
    Events --> Output[Вывести строку в макет:<br/>дата, день недели, корзины,<br/>прогноз, мероприятия]
    Output --> DayLoop
    DayLoop -- конец --> Ret([Табличный документ])
```

Замечания:
- «Глубина» = число дней между датой создания брони и датой заезда; распределяется по 7 корзинам — показывает, насколько заранее бронируют.
- `ПрогнозЗагрузки` — % занятости номерного фонда на день.
- `Мероприятия` города на дату выводятся как фактор спроса.
- 🔴 В модуле 4 почти идентичные версии (`СформироватьНаСервере`, `_1`, `_2`, `_3`) — дублирование, активная версия неочевидна.
