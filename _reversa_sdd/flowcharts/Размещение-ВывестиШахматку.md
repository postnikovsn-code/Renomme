# Flowchart — `ВывестиШахматку(ДатаС, ДатаПо, Детализация)`

> `DataProcessors/Интерфейс/Forms/Форма/Module.bsl:1096-1432` 🟢
> Построение шахматки размещения (сетка «комната × время»).

```mermaid
flowchart TD
    A([Старт: ДатаС, ДатаПо, Детализация]) --> B[Очистить ТЗШахм]
    B --> C{Детализация = День?}
    C -->|Да| D[ДатаС = НачалоДня]
    C -->|Нет| E[ДатаС = НачалоЧаса]
    D --> F[Запрос РС ЗанятостьНомеров за период<br/>Зарезервирован=Истина<br/>статус ≠ ОтказОтБронирования]
    E --> F
    F --> G[Цикл по клиентам:<br/>назначить Цвет по статусу]

    G --> H{Статус брони}
    H -->|Проживает| H1[Белый 255,255,255]
    H -->|Выехал| H2[Серо-бежевый 231,227,217]
    H -->|ОтказОтБронирования| H3[Лосось 233,150,122]
    H -->|иначе| H4{Цвет регистратора?}
    H4 -->|есть| H5[Цвет регистратора]
    H4 -->|нет| H6{Цвет клиента?}
    H6 -->|есть| H7[Цвет клиента]
    H6 -->|нет| H8[СлучайныйЦвет ТЗКлиентов]

    H1 --> I[Второй запрос РС ЗанятостьНомеров<br/>= данные ячеек]
    H2 --> I
    H3 --> I
    H5 --> I
    H7 --> I
    H8 --> I

    I --> J[Вывести шапку:<br/>ось дат/часов, шаг 86400 или 3600*6<br/>метка 12:00 → 14:00]
    J --> K[СпрНомеров = Справочники.НомернойФонд.Выбрать]
    K --> L{Следующий номер?}
    L -->|нет| Z([Вывести ПолеОтчета. Конец])
    L -->|да| M{ПометкаУдаления?}
    M -->|да| L
    M -->|нет| N[Заголовок строки:<br/>Наименование + /РК + /Б<br/>фон = ЦветНомераRGB]
    N --> O[Расшифровка ячейки = ссылка на Номер]
    O --> P[Внутренний цикл по периодам:<br/>НайтиСтроки ПериодРезерва,Номер<br/>→ закрасить ячейку цветом клиента]
    P --> L
```

## Замечания
- Шаги F и I дублируют запрос к `ЗанятостьНомеров` (отдельно цвета клиентов и данные ячеек). 🟡 возможна оптимизация.
- Внутренний цикл закраски (P, стр. 1295-1432) пересекается с логикой брони — детально принадлежит модулю «Бронирование». 🟡
