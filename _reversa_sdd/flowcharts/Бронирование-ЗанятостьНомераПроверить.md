# Flowchart — `ДокументыСервер.ЗанятостьНомераПроверить`

Источник: `CommonModules/ДокументыСервер/Module.bsl:264-311` (+ `ЗанятостьНомераПериодРезерва:231-262`). Доверие: 🟢.

```mermaid
flowchart TD
    Start([ЗанятостьНомераПроверить<br/>РезервС, РезервПо, ВремяЗаезда, ВремяВыезда,<br/>НомерКуда, БонШанс, ТекущийРегистратор]) --> Period[ЗанятостьНомераПериодРезерва]
    Period --> Map[Маппинг часов:<br/>Заезд Вр0/6/14/18 -> 0/6/14/18<br/>Выезд Вр0/6/12/18 -> 24/6/12/18]
    Map --> Calc[НачалоПериода = НачалоЧаса НачалоДня РезервС + Заезд*3600<br/>КонецПериода = НачалоЧаса НачалоДня РезервПо + Выезд*3600]
    Calc --> Q[Запрос к РС ЗанятостьНомеров:<br/>Номер = НомерКуда<br/>ПериодРезерва в Начало..Конец-1<br/>Регистратор &lt;&gt; ТекущийРегистратор]
    Q --> Bon{БонШанс?}
    Bon -- да --> AddCond[+ условие БонШанс = ЛОЖЬ]
    Bon -- нет --> Group[СГРУППИРОВАТЬ по Номер, Регистратор]
    AddCond --> Group
    Group --> Exec[Выполнить запрос]
    Exec --> Has{Найдены строки?}
    Has -- да --> Busy[Результат = Истина<br/>Регистратор = первый конфликт]
    Has -- нет --> Free[Результат = Ложь<br/>Регистратор = Неопределено]
    Busy --> Ret([Структура: Результат, периоды, Регистратор])
    Free --> Ret
```

Замечания:
- `Результат = Истина` означает **номер занят** (конфликт), что в `ОбработкаПроведения` приводит к отказу.
- Бронь «БонШанс» не конфликтует с другими «БонШанс»-резервами (фильтр `БонШанс = ЛОЖЬ`). 🟡
- Период резерва считается с точностью до часа; выезд исключает последний час (`Конец-1` в запросе и `ТемпПо-1` в проведении).
