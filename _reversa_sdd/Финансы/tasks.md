# Финансы и касса, Tarefas de Implementação

> Атомарные задачи для переподнятия модуля из легаси. Каждая цитирует файл-источник, имеет критерий готовности и доверие.
> Шкала: 🟢 подтверждено / 🟡 выведено / 🔴 пробел (требует решения человека — см. questions.md).

## Pré-requisitos
- [ ] Доступны метаданные регистров `Взаиморасчеты/Долги/Деньги`, документов оплаты, справочника `ВидыОпераций`, перечислений `ВидОплаты/ТипОплатыСчета/ВидыДвиженияНакопления`.
- [ ] Доступна ТЧ-модель долгового контура заявки (`СчетаДетальноДолги`, `РаспределениеОплатДолги`, `Счета`) — зависимость от модуля Бронирование.
- [ ] Принято решение по 🔴 из questions.md (контур учёта, мёртвый код, бонусная база) ДО реализации.

## Ordem Sugerida
1. Сначала классификаторы и метаданные (регистры, `ВидыОпераций`, перечисления) — база для всего.
2. Затем валидация + проведение оплат (T-01..T-05) — критический путь.
3. Затем долговой контур (T-06..T-09) — ядро; зависит от ТЧ-модели заявки (модуль Бронирование).
4. Групповые счета (T-10..T-14) — зависят от T-06..T-09.
5. Закрытие периода/месяца/смены (T-15..T-18) — отчётность, зависит от долгового контура.
6. T-18 заблокирована доступностью модуля БПО.
