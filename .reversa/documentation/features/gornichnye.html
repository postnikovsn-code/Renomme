Горничные (Housekeeping)

Как устроена фича · модуль «Горничные (Housekeeping)» 24 860 строк сложность: высокая

Модуль учитывает работу горничных: уборку номеров и помещений, смены, прачечную, расчёт стоимости уборок и сдельной зарплаты. Регистрация уборок ведётся в отдельной базе 1С «Горничные» (планшеты); данные загружаются в «ОТЕЛЬ» по COM, после чего считается зарплата по модели И/Р/Э/Есть.

Назначение

Двусторонне синхронизирует справочники (горничные, помещения, номенклатура минибара) между «ОТЕЛЬ» и БД горничных по COM и загружает факты уборки/смен.

Проводит уборки в регистр УборкиНомеров — основу сдельного учёта — и делит выручку прачечной (НДС, доля отеля, доля горничной).

Рассчитывает зарплату за период: оклад с учётом отпуска, надбавки за стаж и стандарты, отпускные, сдельные уборки и сводный квиток.

Бизнес-правила

  • HK-01Сдельная часть ЗП начисляется только если Горничная.УчетУборок = Истина; иначе 0.
  • HK-02Модель И/Р/Э/Есть: эффективное _Э = ?(_Есть, _Р, _И) для замены; Кол_Э = Кол_И + Кол_Р для количеств.
  • HK-03Цена уборок берётся из ГорничныеСтоимостьУборок — первая запись с датой назначения не позже начала периода.
  • HK-04Оклад с учётом отпуска: Окр(Оклад × РасчётныеДни / ДнейВМесяце), где расчётные дни — за минусом дней отпуска.
  • HK-06Прачечная: НДС, далее доля отеля (по умолчанию 10%), остаток — горничной.
  • HK-07Повторная загрузка пропускает документ с РучноеИзменение=Истина (защита ручных правок).
  • HK-08Защита от эха обмена: записи из обмена (ОбменДанными.Загрузка=Истина) обратно не выгружаются.

Крайние случаи

  • COM-соединение недоступно после 3 попыток — выводится «Нет связи с БД Горничные», операция завершается без изменения данных.
  • При создании задания уборки, если у номера не заполнен НомерГорничные — задание не создаётся, выводится сообщение.
  • Горничная при загрузке ищется по наименованию; при отсутствии авто-создаётся (риск дублей при опечатке имени).
  • COM-выгрузка таблицы фактов обёрнута в пустую Попытка — сбой проглатывается молча, загрузка отработает «по нулю».

Открытые вопросы

  • 🔴 Q-01Хардкод учётных данных COM (Pwd="123", Usr="Соединение").
  • 🔴 Q-02Баг КоличествоЧасовНаКлиенте — умножение на 8 вместо ДлинаСмены; какой расчёт эталонный.
  • 🔴 Q-03Источник СтавкаНДСЧисло в делении выручки прачечной не прослежен.
  • 🔴 Q-04Печатные формы и 4 отчёта (включая сводный квиток) не разобраны вглубь.
  • 🔴 Q-05Закреплённая опечатка ВремяУброки в РС — переименовывать или сохранить ради совместимости запросов.
  • 🟡 Q-10Матрица «профиль отеля → видимые надбавки/поля» формы зарплаты не зафиксирована.
