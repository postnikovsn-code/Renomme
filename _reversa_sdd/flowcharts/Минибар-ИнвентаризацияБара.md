# Flowchart — Инвентаризация бара (контур Товары)

Файлы: `ПСН_РЕНОМЕ__АУДИТ/src/Documents/ИнвентарицацияБара/ObjectModule.bsl` (проведение), `.../Forms/ФормаДокумента/Module.bsl:130-186` (заполнение). Доверие: 🟢.

> ВНИМАНИЕ: этот документ работает по контуру `Catalog.Товары` (группа «Бар») и регистру `ОстаткиПродукции`, а НЕ по `НоменклатураМиниБара`/`МинибарОстатки`.

```mermaid
flowchart TD
    subgraph Заполнение["ЗаполнитьНаСервере (форма)"]
        Кн([Команда Заполнить]) --> Пусто{ТЧ Товары пуста?}
        Пусто -->|нет| Вопрос[Вопрос: ТЧ будет очищена?]
        Вопрос -->|Нет| Стоп([отмена])
        Вопрос -->|Да| Зап
        Пусто -->|да| Зап
        Зап["Запрос: Товары в иерархии группы 'Бар'\n LEFT ОстаткиПродукции.Остатки(&Дата)\n LEFT СебестоимостьТоваров.СрезПоследних(&Дата)"] --> Цикл
        Цикл[Для каждого товара] --> Стр[Строка ТЧ:\nКоличествоУчет=Остаток\nСебестоимость=Себест/?(Остаток=0,1,Остаток)\nРасхождение=Факт-Учёт]
        Стр --> Цикл
    end

    Цикл --> Ред

    subgraph Редактирование["Ручной ввод факта"]
        Ред[ТоварыПриОкончанииРедактирования] --> Пересчёт[Расхождение =\nКоличествоФакт - КоличествоУчет]
        Пересчёт --> Оформл["Условное оформление:\n=0 зелёный, >0 светло-зелёный, <0 коралл"]
    end

    Оформл --> Провод

    subgraph Проведение["ОбработкаПроведения"]
        Провод[Для каждой строки ТЧ Товары] --> Ноль{Расхождение = 0?}
        Ноль -->|да| След[пропуск, след. строка]
        Ноль -->|нет| Знак{Расхождение > 0?}
        Знак -->|да| Прих[Движение ОстаткиПродукции\nПриход = Факт - Учёт]
        Знак -->|нет| Расх[Движение ОстаткиПродукции\nРасход = -1*(Факт - Учёт)]
        Прих --> След
        Расх --> След
        След --> Провод
    end

    Провод --> Конец([КонецПроцедуры])
```

## Замечания
- 🟢 Инвентаризация = `Факт − Учёт`: положительное расхождение приходует, отрицательное — расходует `ОстаткиПродукции`, выравнивая учёт по факту.
- 🔴 Магическая строка `Справочники.Товары.НайтиПоНаименованию("Бар")` — привязка к имени группы товаров.
- 🟢 Себестоимость в ТЧ — за единицу (`Себест / Остаток`), берётся из среза `СебестоимостьТоваров`.
- 🟡 Связь этого контура с минибаром (`НоменклатураМиниБара`) в коде не обнаружена — вероятно, два независимых товарных учёта.
