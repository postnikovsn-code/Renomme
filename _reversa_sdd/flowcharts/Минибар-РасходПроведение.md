# Flowchart — `МинибарРасход.ОбработкаПроведения` (FIFO-списание партий)

Файл: `ПСН_РЕНОМЕ__АУДИТ/src/Documents/МинибарРасход/ObjectModule.bsl:2-98`. Доверие: 🟢.

Самый сложный алгоритм модуля. На каждую строку расхода списывает количество с партий минибара по принципу FIFO (старейшая партия первой).

```mermaid
flowchart TD
    Старт([ОбработкаПроведения]) --> ОстаткиЦикл

    subgraph ОстаткиБлок["1. Регистр МинибарОстатки -расход"]
        ОстаткиЦикл[Для каждой строки ТЧ Расход] --> ДвижОст[Движение МинибарОстатки\nВид=Расход, Период=ДатаРасхода\nКоличество, ЦенаРасход\nСуммаРасход=Цена*Кол-во]
    end

    ДвижОст --> ПартииЦикл

    subgraph ПартииБлок["2. Регистр МинибарПартии (FIFO)"]
        ПартииЦикл[Для каждой строки ТЧ Расход] --> ПолучОст["ПартииОстатки(ДатаРасхода, Номенклатура)\n= остатки партий, упорядочены по дате прихода"]
        ПолучОст --> Коррекция[Скорректировать КоличествоОстаток\nна уже добавленные движения\nэтого проведения по той же партии]
        Коррекция --> Инит[РасходОстаток = Количество строки]
        Инит --> ПартияЦикл{Для каждой партии\nот старейшей}

        ПартияЦикл -->|КоличествоОстаток > 0| Доб[Движение Расход:\nДокументПрихода, ЦенаПриход партии,\nЦенаРасход строки]
        ПартияЦикл -->|остаток = 0| СледПартия[след. партия]
        СледПартия --> ПартияЦикл

        Доб --> Хватает{РасходОстаток >\nКоличествоОстаток?}
        Хватает -->|да| Частично[Списать всю партию;\nРасходОстаток -= КоличествоОстаток]
        Хватает -->|нет| Полностью[Списать РасходОстаток;\nПрервать]
        Частично --> ПартияЦикл

        Полностью --> Проверка
        ПартияЦикл -->|партии кончились| Проверка{РасходОстаток > 0?}
        Проверка -->|да| БезПартии["🔴 Движение Расход\nБЕЗ ДокументПрихода\n(торговля в минус, себест.=0)"]
        Проверка -->|нет| КонецСтроки[след. строка расхода]
        БезПартии --> КонецСтроки
    end

    КонецСтроки --> Конец([КонецПроцедуры])
```

## Подзапрос `ПартииОстатки`
```sql
ВЫБРАТЬ ДокументПрихода, НоменклатураМинибара, КоличествоОстаток, ЦенаПриход
ИЗ РегистрНакопления.МинибарПартии.Остатки(&Дата[Включая], НоменклатураМинибара = &Номенклатура)
ГДЕ КоличествоОстаток > 0
УПОРЯДОЧИТЬ ПО ДокументПрихода.ДатаДокументаПрихода   -- задаёт порядок FIFO
```

## Замечания
- 🟢 Коррекция остатков на движения текущего проведения (стр. 21-29) предотвращает двойное списание одной партии при нескольких строках расхода одной номенклатуры.
- 🔴 Ветка «без партии» (стр. 54-61) уводит `МинибарПартии` в минус и даёт нулевую себестоимость — допущение «торговли в минус».
- 🟢 `МинибарОстатки` и `МинибарПартии` пишутся независимо: первый — простой -расход, второй — разложение по партиям.
