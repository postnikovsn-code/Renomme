# Flowchart — Модуль «Аудит и отчётность»

> Поток уровня модуля: ночной аудит (закрытие дня) → витрины РС → управленческие/операционные отчёты. Доверие: 🟢 подтверждено кодом, 🟡 выведено.

```mermaid
flowchart TD
    subgraph NightAudit["Ночной аудит — закрытие дня (Документ.ЕжедневныйАудит)"]
        A1[Открыть/создать ЕжедневныйАудит<br/>ДатаОтбора = день]
        A2["ЗаполнитьТаб(): запрос проживающих<br/>из РС ЗанятостьНомеров + оплаты"]
        A3["ПроживаниеОтклонение():<br/>факт время заезда/выезда vs тариф"]
        A4[ТЧ ПроданныеНомера: план/факт/<br/>отклонение/часы/оплаты]
        A5[ТЧ Незаезды / Аннуляции]
        A6{Флаг Проверка?}
        A7[Проведение: движения<br/>РС ПроданныеНомера]
        A1 --> A2 --> A3 --> A4
        A2 --> A5
        A4 --> A6
        A6 -- да --> A7
        A6 -- нет --> A8[Движения не пишутся]
    end

    subgraph Sources["Первичные источники"]
        S1[(РС ЗанятостьНомеров)]
        S2[(Док ЗаявкаНаБронирование<br/>ТЧ Проживание/ДопУслуги/Счета)]
        S3[(Док КассовыйДокумент / ВыпискаБанка)]
        S4[(Справ. НомернойФонд)]
    end

    subgraph Marts["Витрины (кэш)"]
        M1[(РС ПроданныеНомера)]
        M2[(РС ЕжедневныйОтчетФакт)]
    end

    subgraph FactReport["Ежедневный факт-отчёт"]
        F1["CM ЕжедневныйОтчетФакт.ТЗ_ОтчетДанные()"]
        F2["ЗаполнитьРегистрЕжедневныйОтчетФакт()"]
        F3[Метрики: ADR, загрузка %,<br/>ср. стоимость, B2B, комиссия]
        F4[Табличный документ]
        F5["Сводный по сети отелей<br/>(HTTP: Реноме/Лайв/Чехов/...)"]
        F1 --> F2 --> M2 --> F3 --> F4
        F2 --> F5
    end

    subgraph Reports["Подсистема отчётов (39 шт.)"]
        R1[Финансы/выручка: ФинансовыйОтчет,<br/>СтатистикаОплаты, НеОплаты, ...]
        R2[Загрузка/продажи: ОтчетПоПоказателям,<br/>ОтчетПоПродажам, СтатистикаПоНомерам, ...]
        R3[Спрос: СтатистикаБронирования,<br/>ИсточникиБронирования, ГлубинаБрон., ...]
        R4[Качество/горничные/минибар: ...]
    end

    S1 --> A2
    S2 --> A2
    S3 --> A2
    S4 --> F1
    S2 --> F1
    A7 --> M1
    M1 --> R1
    M2 --> R1
    S1 --> R2
    S2 --> R3
    S1 --> R3
    M1 --> R1
```

**Ключевые узлы:**
- 🟢 `Проверка` — тумблер: без него аудит не пишет движения.
- 🟢 Витрина РС `ПроданныеНомера` наполняется только аудитом, читается финансовыми отчётами.
- 🟢 Факт-отчёт перед выводом **пересчитывает и перезаписывает** РС `ЕжедневныйОтчетФакт`.
- 🟡 Сводный отчёт собирает данные по 5 отелям сети по HTTP (имена захардкожены).
