# Flowchart — `ЗаявкаНаБронирование.ОбработкаПроведения`

Источник: `Documents/ЗаявкаНаБронирование/ObjectModule.bsl:4-140`. Доверие: 🟢.

```mermaid
flowchart TD
    Start([ОбработкаПроведения]) --> Val{ПроверкаЗаполнения<br/>ok?}
    Val -- нет --> Cancel1[Отказ = Истина] --> End([Возврат])
    Val -- да --> WL{ЛистОжидания?}
    WL -- да --> End
    WL -- нет --> St{Статус =<br/>Отмена/Отказ?}
    St -- да --> End
    St -- нет --> Occ[ЗанятостьНомераПроверить<br/>РезервС..РезервПо, номер]
    Occ --> OccR{Номер занят<br/>другим регистратором?}
    OccR -- да --> Msg[Сообщить 'Номер занят'] --> Cancel2[Отказ = Истина] --> End
    OccR -- нет --> Hist[ЗаявкаСервер.ОбновитьИсториюКлиента]

    Hist --> Day{РезервС = РезервПо?}
    Day -- да --> Spec[Спец-обработка суток:<br/>+24ч или окно 13:00-18:00]
    Day -- нет --> Norm[ТемпС/ТемпПо =<br/>период резерва]
    Spec --> Adj[ТемпПо = ТемпПо - 1]
    Norm --> Adj

    Adj --> QExist[Запрос: существующие<br/>записи занятости часа]
    QExist --> Loop{ТемпС < ТемпПо?}
    Loop -- да --> Move[Движение ЗанятостьНомеров:<br/>Номер, Клиент, час, Зарезервирован,<br/>БонШанс, Номер_пп+1 если есть]
    Move --> Inc[ТемпС += 3600] --> Loop
    Loop -- нет --> Accounts{По каждому<br/>счёту в Счета}
    Accounts --> MoveAcc[Движение Взаиморасчеты:<br/>Расход на СуммаДолг счёта]
    MoveAcc --> Accounts
    Accounts -- конец --> End
```

Замечания:
- Почасовой цикл создаёт по записи `ЗанятостьНомеров` на каждый час интервала резерва — гранулярность доступности = 1 час.
- `Номер_пп` инкрементируется при наложении резервов в одном часе (мульти-резерв/переселение).
- 🔴 Движения `Долги`/`ОстаткиПродукции`/`ПродажиТоваров` заявлены в регистраторах, но в этой процедуре не формируются (мёртвый/перенесённый блок `:96-138`).
