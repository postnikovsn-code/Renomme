# Сценарий — Пробитие фискального чека (БПО)

> Источник: `CommonModules/ОплатыЧекКлиент/Module.bsl` (`ЧекОплаты`, `ЧекОплатыДействие`,
> `ЗаполнитьПозицииЧекаККМОплата*`, `ФУ_ПечатьТекста`), `CommonModules/ФУ_Клиент/Module.bsl`
> (`ВыполнитьОперацию`, `ОперацияЗавершение`), фасад
> `ОборудованиеЧекопечатающиеУстройстваКлиент/КлиентСервер`.
> 🟡 Низкоуровневое формирование фискального документа и связь с ФН — внутри библиотеки БПО.

```mermaid
flowchart TD
  Start([Оплата по счёту/долгу гостя]) --> Chek["ОплатыЧекКлиент.ЧекОплаты(ДопПараметры, Форма)"]
  Chek --> Act["ЧекОплатыДействие(ДопПараметры)"]
  Act --> Fill["ЗаполнитьПозицииЧекаККМОплата(...)<br/>проживание/допуслуги/коворкинг/аванс"]
  Fill --> Lines["ПараметрыФискальнойСтрокиЧека() ×N<br/>(ОборудованиеЧекопечатающиеУстройстваКлиентСервер)"]
  Lines --> Pay["ПараметрыСтрокиОплаты()<br/>(нал/безнал, суммы)"]
  Pay --> Org["ФУ_Сервер: ДанныеОрганизацииДляФУ(), Кассир(ЭтоКоворкинг)"]
  Org --> Params["ПараметрыОперацииФискализацииЧека()"]
  Params --> Branch{Способ фискализации}

  Branch -->|Локальная ККТ| Local["ОборудованиеЧекопечатающиеУстройстваКлиент.<br/>НачатьПробитиеЧека(...)"]
  Branch -->|Сервер ККМ| SKKM["СерверККМ.ВыполнитьЗапрос(HTTP)"]
  Branch -->|Облачная ККТ| Cloud["ОборудованиеЧекопечатающиеОблачныеККТ*"]
  Branch -->|Распределённая| RF["РаспределеннаяФискализация → РС ОчередьЧековККТ"]

  Local --> Done["ФУ_Клиент.ОперацияЗавершение(Результат, Параметры)"]
  SKKM --> Done
  Cloud --> Done
  RF --> Done
  Done --> Reg["РС ФискальныеОперации (история, чистится регламентом)"]
  Reg --> EChek{Электронный чек нужен?}
  EChek -->|Да| Queue["Catalog.ОчередьЭлектронныхЧековКОтправке<br/>→ ScheduledJob.РассылкаЭлектронныхЧеков"]
  EChek -->|Нет| End([Чек напечатан])
  Queue --> End
```

**Ключевые точки (🟢):**
- Домен формирует **позиции и оплаты** (`ОплатыЧекКлиент`), библиотека — собственно фискализацию.
- Поддержка маркировки: при наличии КМ — через `МенеджерОборудованияМаркировка*` (проверка ФЛК/ИСМ).
- 4 способа фискализации сосуществуют (локальная / Сервер ККМ / облачная / распределённая через очередь).
