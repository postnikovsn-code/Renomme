# Flowchart модуля «Финансы и касса»

> Уровень: detalhado. Шкала доверия: 🟢 подтверждено / 🟡 выведено / 🔴 пробел.
> Домен: деньги, долги, взаиморасчёты гостей/контрагентов, кассовые документы,
> банковские выписки, групповые счета, закрытие финансового периода.

## Архитектура движений (кто пишет в регистры-ядро)

```mermaid
flowchart TD
    subgraph Источники["Документы-источники движений"]
        Заявка["Документ.ЗаявкаНаБронирование<br/>(модуль Бронирование)"]
        КассДок["Документ.КассовыйДокумент<br/>(оплата наличными/картой)"]
        Выписка["Документ.ВыпискаБанка<br/>(безналичная оплата)"]
        ПрочиеОпл["Документ.ПрочиеОплаты<br/>(взаимозачёт/списание)"]
        ВзаимКор["Документ.ВзаиморасчетыКоректировка<br/>(ручная корректировка)"]
        ГашениеСтар["Документ.ГашениеДолгов_Старая<br/>(устаревший)"]
    end

    subgraph Регистры["РегистрыНакопления (ядро модуля)"]
        РВзаим[("Взаиморасчеты<br/>Контрагент → Сумма, СуммаКомисииРасчет")]
        РДолги[("Долги<br/>ДокументДолг, Контрагент → Сумма")]
        РДеньги[("Деньги<br/>ВидОплаты, Контрагент, КредитнаяКарта, Оплата → Сумма")]
    end

    Заявка -->|"Приход: возникает долг"| РДолги
    Заявка -->|"Расход по счёту"| РВзаим
    КассДок -->|"только Взаиморасчеты<br/>(остальное dead-code)"| РВзаим
    Выписка -->|"только Взаиморасчеты"| РВзаим
    ПрочиеОпл -->|"только Взаиморасчеты"| РВзаим
    ВзаимКор --> РВзаим
    ГашениеСтар -->|"Расход: долг погашен"| РДолги

    РДеньги -.->|"🔴 пишется только<br/>мёртвым кодом после Возврат"| КассДок
```

## Сквозной поток оплаты долга гостя (фактический контур через ТЧ заявки)

```mermaid
flowchart TD
    A["Гость выезжает / выставлен счёт"] --> B["ЗаявкаНаБронирование.СчетаДетальноДолги<br/>СуммаДолг, СуммаКЗакрытию, СуммаОплачено"]
    B --> C{"Тип оплаты"}
    C -->|"Наличные/Карта"| D["КассовыйДокумент"]
    C -->|"Безнал"| E["ВыпискаБанка"]
    C -->|"Взаимозачёт/Списание"| F["ПрочиеОплаты (ВидОперации)"]

    D & E & F --> G["Движение Взаиморасчеты<br/>(Приход/Расход по флагу Приход)"]
    D & E & F --> H["Распределение оплаты по долгам<br/>ЗаявкаОбщееКлиентСервер.<br/>РаспределитьОплатаНаСчетаДетальноДолги"]
    H --> I["FIFO по строкам СчетаДетальноДолги:<br/>гасим СуммаКЗакрытию пока есть остаток оплаты"]
    I --> J["ТЧ РаспределениеОплатДолги += СуммаОплаты"]
    J --> K{"СуммаКЗакрытию = 0 по всем строкам?"}
    K -->|"Да"| L["Заявка закрыта (долг погашен)"]
    K -->|"Нет"| M["Остаётся долг → попадёт в отчёт закрытия периода"]
```

## Закрытие финансового периода / месяца

```mermaid
flowchart TD
    S["Обработка.ЗакрытиеФинансовогоПериода"] --> T["Запрос по ЗаявкаНаБронирование<br/>Статус = Выехал/Неустойка, РезервПо в [ДатаС; ДатаПо]"]
    T --> U["Соединяем: Проживание, ДопУслуги(ВСчет),<br/>СчетаДетальноДолги (СуммаДолг/СуммаКЗакрытию),<br/>РаспределениеОплатДолги (списания)"]
    U --> V1["Отчёт «Долги»:<br/>СуммаКЗакрытию > 0"]
    U --> V2["Отчёт «Списание»:<br/>ВидОперации ∈ {Списание, СписаниеЗачет, СписаниеДопУслуг}"]
    V2 --> W["Разбивка списаний доп.услуг:<br/>МИНИБАР / ПРАЧЕЧНАЯ / прочее<br/>по ПрограммныйКодУслуги"]

    S2["Обработка.ЗакрытиеДокументов"] --> T2["Заявки Статус=Выехал за месяц,<br/>проверка месяц закрытия < текущий"]
    T2 --> U2["Пометка Закрыто=Истина по заявкам"]

    S3["Обработка.ЗакрытьСмену"] --> P["ФУ_Клиент.ЗакрытьСмену<br/>(фискальный регистратор, модуль БПО)"]
```
