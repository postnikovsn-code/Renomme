# Flowchart — Модуль «Размещение и номерной фонд»

> Модульный уровень: основные объекты номерного фонда и их связи.
> Шкала доверия: 🟢 ПОДТВЕРЖДЕНО · 🟡 ВЫВЕДЕНО · 🔴 ПРОБЕЛ.

## Граф объектов и потоков

```mermaid
flowchart TB
    subgraph Справочники[Справочники номерного фонда]
        НФ[Catalog НомернойФонд<br/>иерархия=здания, реквизит Этаж]
        КН[Catalog КатегорииНомеров<br/>+ базовые тарифы]
        КНС[Catalog КатегорииНомеровСайт]
        ENH[Enum КатегорииХостела<br/>М/Ж/О]
    end

    subgraph Документы
        ОН[Document ОсмотрНомера]
    end

    subgraph Регистры[Информационные регистры]
        ЗН[РС ЗанятостьНомеров<br/>Номер×Клиент×ПериодРезерва]
        ЗПН[РС ЗамечанияПоНомерам]
        ПН[РС ПроданныеНомера]
    end

    subgraph Обработки
        ИНТ[DataProcessor Интерфейс<br/>ШАХМАТКА размещения]
        ЗАМ[DataProcessor ЗаменаНомеровВЗаявках]
        ЗЛ[ЗагрузкаНомеровЛайв]
        ЗР[ЗагрузкаНомеровРеноме]
        ЗЧ[ЗагрузкаНомеровЧехов]
    end

    КН --> НФ
    ENH --> НФ
    КН --> КНС
    НФ -. ТЧ Соседи / ОбщийКондиционер .-> НФ

    ОН -->|ОбработкаПроведения| ЗПН
    ОН --> НФ

    ИНТ -->|читает| ЗН
    ИНТ -->|строки = комнаты| НФ
    ЗАМ -->|перепроводит| BR[(Document ЗаявкаНаБронирование)]

    ЗЛ -->|COM-импорт| НФ
    ЗР -->|COM-импорт| НФ
    ЗЧ -->|COM-импорт| НФ
    ЗЛ --> КН

    НФ -. ПередЗаписью: зеркало .-> HK[(Внешняя БД Горничные)]

    BR -. RecorderSubordinate .-> ЗН
    BR -. запись .-> ПН

    classDef ext fill:#eee,stroke:#999,stroke-dasharray:5 5;
    class HK,BR ext;
```

## Границы модуля

- **Запись в `ЗанятостьНомеров`/`ПроданныеНомера`** — модуль **Бронирование** (здесь только структура и чтение шахматкой). 🟢
- **Зеркалирование во внешнюю БД горничных** и каталог `ГорничныеНомера` — модуль **Горничные**. 🟢
- **Базовые тарифы в `КатегорииНомеров`** и расчёт проживания — модуль **Ценообразование**. 🟡
- **`КатегорииНомеровСайт`** питает сопоставление при импорте брони с сайта — модуль **Интеграции**. 🟡
- **Коворкинг** (`КоворкингШахматка`, `КоворкингНомера`, `ЗанятостьНомеровКоворкинг`) — НЕ этот модуль (только признак `Коворкинг` на номере). 🟢
