# Финансы и касса, Крайние случаи

> Уровень: detalhado. Минимум 2 крайних случая; ниже — 5.
> Шкала доверия: 🟢 подтверждено / 🟡 выведено / 🔴 пробел.

## EC-01 — Оплата больше суммарного долга 🟢
**Источник:** `CommonModules/ЗаявкаОбщееКлиентСервер/Module.bsl:73-81` (цикл) + `:64-70` (коды возврата).

**Сценарий.** Сумма оплаты превышает `Σ СуммаКЗакрытию` по всем строкам `СчетаДетальноДолги`.

**Поведение легаси.** FIFO закрывает все строки (`СуммаКЗакрытию=0`, `СуммаОплачено=СуммаДолг`), цикл доходит до конца с `ОстатокКРаспределению > 0` и возвращает `0`. Излишек **остаётся нераспределённым** — система не создаёт переплату/аванс автоматически.

**Ожидание при переподнятии.** Возвращать нераспределённый остаток вызывающему коду; не терять его молча. Решение, что делать с переплатой (аванс/возврат), — за вышестоящим контуром (групповой счёт возвращает остаток, см. EC-03).

## EC-02 — Частичная оплата строки долга 🟢
**Источник:** `CommonModules/ЗаявкаОбщееКлиентСервер/Module.bsl:38-48`.

**Сценарий.** Оплата меньше `СуммаКЗакрытию` текущей строки (`ОплатыОстаток ≤ 0`).

**Поведение легаси.** `СуммаОплаты = ОстатокКРаспределению`; `СуммаКЗакрытию −= ОстатокКРаспределению`; `СуммаОплачено += СуммаОплаты`; `ОстатокКРаспределению = 0`; возврат `-1`. Строка остаётся открытой с уменьшенным остатком.

**Ожидание при переподнятии.** Долг гасится частично, строка не закрывается; повторная оплата той же пары (ДокументОплаты, ДолгиГУИД) накапливается идемпотентно (EC-04).

## EC-03 — Групповой счёт с остатком после распределения 🟢
**Источник:** `CommonModules/ГрупповойСчетСервер/Module.bsl:453-529`, `flowcharts/Финансы-ГашениеДолгов.md`.

**Сценарий.** Оплата по групповому счёту больше суммарного долга всех броней группы, либо часть броней уже закрыта (`СуммаСчетаКЗакрытию=0`).

**Поведение легаси.** Закрытые брони пропускаются; на каждую открытую идёт `Мин(Остаток, СуммаСчетаКЗакрытию)`; при остатке ≤ 0 цикл прерывается (`Прервать`); нераспределённый остаток возвращается вызывающему.

**Ожидание при переподнятии.** Бронь не может быть погашена больше своего долга; остаток группового счёта возвращается явно (не «зависает»).

## EC-04 — Повторная оплата того же долга (идемпотентность) 🟢
**Источник:** `CommonModules/ЗаявкаОбщееКлиентСервер/Module.bsl:50-62`.

**Сценарий.** Одна и та же оплата распределяется на ту же строку долга повторно (перепроведение/повторный вызов).

**Поведение легаси.** Поиск строки `РаспределениеОплатДолги` по `Структура("ДокументОплаты, ДолгиГУИД", ...)`; если найдена — берётся существующая, `СуммаОплаты += СуммаОплаты`, дубль не создаётся.

**Ожидание при переподнятии.** Распределение по паре (ДокументОплаты, ДолгиГУИД) идемпотентно по строкам, но **сумма накапливается** — перепроведение без сброса предыдущего распределения завышает `СуммаОплаты`. При переподнятии необходимо очищать `РаспределениеОплатДолги` перед повторным распределением одной оплаты. 🟡

## EC-05 — Касса: раскладка суммы не сходится 🟢
**Источник:** `Documents/КассовыйДокумент/ObjectModule.bsl:179-183`.

**Сценарий.** `Сумма ≠ СуммаКарта + СуммаНаличные` (например, Сумма=1000, Карта=600, Наличные=300).

**Поведение легаси.** `ТекстОшибки()` добавляет «Сумма <> Сумма Карта + Сумма Наличные»; `ОбработкаПроведения` выводит сообщение «… Документ НЕ сохранен», ставит `Отказ=Истина` и `Возврат` — документ не проводится, движений нет.

**Ожидание при переподнятии.** Контроль раскладки — жёсткое бизнес-правило кассы; без него нельзя провести документ. В `ВыпискаБанка`/`ПрочиеОплаты` этого контроля нет (только касса).

## EC-06 — Закрытие периода с незакрытыми долгами 🟢
**Источник:** `DataProcessors/ЗакрытиеФинансовогоПериода/Forms/Форма/Module.bsl:39-392`, `flowcharts/Финансы-ЗакрытиеПериода.md`.

**Сценарий.** На конец периода у заявок Выехал/Неустойка остаётся `СуммаКЗакрытию > 0`.

**Поведение легаси.** Это **отчёт-сверка**, а не проводящий документ: незакрытые долги попадают в отчёт «Долги» (итог `СуммаДолга`, счётчик полностью закрытых отдельно). Закрытие периода не «принудительно» гасит и не списывает долги — только показывает их. Расхождение `СуммаПроживаниеСчета ≠ СуммаПроживание` подсвечивается красным.

**Ожидание при переподнятии.** Закрытие периода не должно менять долговое состояние; незакрытые долги остаются и переходят в следующий период. Списание — отдельная операция (`ПрочиеОплаты` с `ВидОперации ∈ Списание*`).
